## Wave 1 — Tenant System Gallery (backend)

### Objective

Add tenant-level S3 storage + admin media API for managing shared system images.

### Tasks

#### 1.1 Tenant storage functions

**File:** `src/shared/api/storage.ts`

Add three new exports:

```typescript
export async function uploadTenantImage(
  file: File,
  tenantId: string,
  userId: string
): Promise<UploadResult>;

export async function listTenantImages(tenantId: string): Promise<MediaItem[]>;

export async function deleteTenantImage(
  key: string,
  tenantId: string
): Promise<{ success: boolean; error?: string }>;
```

- Uses prefix `tenants/${tenantId}/system/` for all three operations
- `uploadTenantImage` includes the same validation (file type, size 2MB) as `uploadImage`
- `deleteTenantImage` verifies key starts with `tenants/${tenantId}/system/` for safety
- `listTenantImages` lists all objects under the tenant system prefix

#### 1.2 Admin media API route

**File:** `src/app/api/admin/media/route.ts`

Three operations, admin-gated via `hasPermission(role, 'admin')`:

- **GET** — List tenant system images → `listTenantImages(tenantId)`
- **POST** — Upload image → `uploadTenantImage(file, tenantId, userId)`, rate-limited 10/min/user
- **DELETE** — Delete by key → `deleteTenantImage(key, tenantId)`

Pattern follows `src/app/api/upload/route.ts` and `src/app/api/media/route.ts`.

## Wave 3 — Public Album Sharing

### Objective

Expose public albums across the tenant + new community gallery widget.

#### 3.1 Public albums API

**File:** `src/app/api/user/albums/public/route.ts` (new)

**GET** — Lists all albums where `isPublic = true` within the current tenant:

```typescript
db.select()
  .from(albums)
  .where(and(eq(albums.tenantId, tenantId), eq(albums.isPublic, true)))
  .orderBy(desc(albums.createdAt));
```

Returns album metadata including `id`, `title`, `description`, `mediaIds`, `createdAt`, and the `userId` of the owner (for resolving display name/avatar).

**Note:** This does NOT return the full media URLs — that requires resolving S3 keys per user's storage prefix. Each album item returns `mediaIds` (S3 keys); the frontend constructs URLs since all images are public-read.

#### 3.2 Community gallery widget

**File:** `src/widgets/dashboard/ui/CommunityGalleryWidget.tsx` (new)

- Fetches `GET /api/user/albums/public`
- Displays public albums in a card grid (reuses the card pattern from `MyAlbumWidget`)
- Each card shows: album title, description (line-clamped), media count, owner, first 4 thumbnail images
- Clicking expands/reveals album contents (inline expand, same pattern as MyAlbumWidget)
- Empty state: "No public albums from the community yet"
