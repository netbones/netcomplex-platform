# Existing i18n patterns in codebase:

## useTranslation pattern:

- Client components use: `const { t } = useTranslation('namespace')`
- Multiple namespaces: `const { t, t: tCommon } = useTranslation(['common', 'dashboard'])`
- Check for ready state: `const { t, ready } = useTranslation('common')`

## LanguageSwitcher (existing):

- Located at src/components/ui/LanguageSwitcher.tsx
- Uses select dropdown with dark theme styling (white text, white/10 bg)
- Uses i18n.changeLanguage() for switching
- Uses supportedLanguages and languageNames from @/lib/i18n
- Shows language name on hover

## Translation files:

- Location: public/locales/{lng}/{namespace}.json
- Example: public/locales/en/common.json, public/locales/en/dashboard.json
- Structure: nested keys like "nav.home", "hero.title"

## Namespaces available:

- common, dashboard, services, messages, forms, resources, conservation, groups, interest, maintenance, bookings, notifications, directory, admin
