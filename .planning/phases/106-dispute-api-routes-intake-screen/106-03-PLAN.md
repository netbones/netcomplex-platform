9. Record usage: recordUsage({ tenantId, capability: CAPABILITY, userId, referenceId: disputeId, provider: result.provider, model: mapProviderToModel(provider.name), inputTokens: estimateInputTokens(sanitised), outputTokens: result.tokensUsed ?? 0, durationMs: Date.now() - start, success, errorCode }, db) — CALLED ALWAYS even on failure
