## Trust Boundaries

| Boundary                    | Description                                                                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Client browser → API routes | All API calls authenticated via Better Auth session cookie. Role checks enforced server-side regardless of client UI state.                              |
| Client state → Server state | Client never trusts its own role/status assessment — all action gates (Submit, Assign, Ruling, Withdraw, Delete) validated server-side before execution. |
| Realtime channel (Supabase) | Channel `dispute:{id}` subscribed with anon key; visibility filtering applied client-side but server enforces isInternal on POST — defense in depth.     |
| File system (drag-and-drop) | MIME validation client-side for UX, but uploadImage() validates server-side as primary enforcement.                                                      |
