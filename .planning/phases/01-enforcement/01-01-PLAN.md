## Phase 1: Wire TenantStyles to Database

### Current State

TenantStyles.tsx currently uses hardcoded defaults:

- primaryColor = '#4F46E5'
- accentColor = '#F59E0B'
- secondaryColor = '#10B981'
- fontFamily = 'Inter'

### Required Changes

Create a server component wrapper that fetches tenant from DB and passes to TenantStyles:

1. Create src/components/tenant/TenantStylesLoader.tsx:

```typescript
import { getCurrentTenant } from '@/lib/tenant';
import { TenantStyles } from './TenantStyles';

export async function TenantStylesLoader() {
  const tenant = await getCurrentTenant();

  if (!tenant) {
    return <TenantStyles />;
  }

  return (
    <TenantStyles
      primaryColor={tenant.primaryColor || '#4F46E5'}
      accentColor={tenant.accentColor || '#F59E0B'}
      secondaryColor={tenant.secondaryColor || '#10B981'}
      fontFamily={tenant.fontFamily || 'Inter'}
    />
  );
}
```

2. Update src/app/layout.tsx to use TenantStylesLoader:

```typescript

// In the root layout, replace direct TenantStyles with:
<TenantStylesLoader />
// (placed in the html body)
```

3. Verify the tenant table has the required columns (already present in tenants.ts):

- primaryColor
- accentColor
- secondaryColor
- fontFamily

### Why this works

- getCurrentTenant() already exists in lib/tenant.ts
- TenantStyles already accepts props for all color/font values
- This enables per-tenant branding without code changes
