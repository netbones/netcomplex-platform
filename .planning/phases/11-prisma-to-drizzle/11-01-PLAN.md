# Phase 11-01: Migrate Away from Prisma

## Context

The project currently uses **two ORM layers**:

- **Drizzle** — the intended ORM for all runtime queries (edge-compatible, used in `src/shared/api/db.ts`)
- **Prisma** — used only as a schema source + code generator (`prisma-generator-drizzle` generates `prisma/drizzle/*`)

Prisma is **not used at runtime** in application code. However it creates confusion because:

1. `@prisma/client` is a production dependency but never called at runtime
2. `prisma generate` runs on every build (slow, unnecessary at runtime)
3. `src/shared/api/prisma.ts` exists as a dead singleton
4. `prisma/seed.ts` uses Prisma client with wrong enum values (stale)
5. The `@prisma/*` path alias maps to generated Drizzle files — confusing naming

## Goal

Remove Prisma from the runtime dependency chain entirely. Keep the schema workflow but make it Drizzle-native.

---

## Current State

```
prisma/schema.prisma          ← source of truth for schema
  └─ prisma-generator-drizzle ← generates prisma/drizzle/*.ts
       └─ prisma/drizzle/     ← Drizzle table definitions (used at runtime)
            └─ @prisma/* alias ← confusingly named path alias
```

## Target State

```
prisma/schema.prisma          ← source of truth for schema (keep for migrations)
  └─ prisma-generator-drizzle ← generates src/db/schema/*.ts  (renamed output)
       └─ src/db/schema/      ← Drizzle table definitions (used at runtime)
            └─ @schema/* alias ← clear naming
```

---

## Migration Steps

### Step 1 — Remove dead Prisma runtime code

- [x] Delete `src/shared/api/prisma.ts` (unused singleton)
- [x] Delete `prisma/seed.ts` (replaced by `scripts/seed-drizzle.ts`)
- [x] Remove `@prisma/client` from `dependencies` in `package.json`
- [x] Remove `@better-auth/prisma-adapter` from `dependencies` (auth uses Drizzle adapter)
- [x] Remove `@prisma/client` from `devDependencies` if present

### Step 2 — Update build script

- [x] Remove `prisma generate &&` from the `build` script in `package.json`
- [x] Add `db:generate` as a standalone `db:generate` script
- [x] Keep `db:push` as `prisma db push` (still useful for schema migrations)

### Step 3 — Rename generated output directory

- [x] Update `prisma/schema.prisma` generator config:
  ```prisma
  generator drizzle {
    provider = "prisma-generator-drizzle"
    output   = "../src/db/schema"
  }
  ```
- [x] Run `prisma generate` to regenerate into `src/db/schema/`
- [x] Delete `prisma/drizzle/` directory

### Step 4 — Update path aliases

- [x] In `tsconfig.json`, rename `@prisma/*` → `@schema/*`:
  ```json
  "@schema/*": ["./src/db/schema/*"]
  ```
- [x] Update `src/shared/api/db.ts` — replace all `from '@prisma/*'` imports with `from '@schema/*'`
- [x] Update any other files using `@prisma/*` imports

### Step 5 — Create a native Drizzle schema index

- [x] Create `src/db/index.ts` that re-exports all tables from `src/db/schema/`
      (replaces the generated `prisma/drizzle/schema.ts`)
- [x] Update `src/shared/api/db.ts` to import from `@db/schema` instead of individual `@prisma/*` paths

### Step 6 — Validate

- [x] Run `pnpm typecheck` — no type errors
- [ ] Run `pnpm build` — should succeed without Prisma client (validation pending)
- [ ] Run `pnpm db:seed` — should seed correctly (validation pending)
- [x] Confirm `@prisma/client` is not in the production bundle

## Risk Assessment

| Risk                                         | Likelihood | Mitigation                                  |
| -------------------------------------------- | ---------- | ------------------------------------------- |
| Missing table import after rename            | Medium     | Grep for `@prisma/` before deleting         |
| `prisma db push` still needed for migrations | Low        | Keep Prisma as devDependency only           |
| Better Auth adapter breakage                 | Low        | Already uses `@better-auth/drizzle-adapter` |

## Notes

- `prisma/schema.prisma` remains the schema source of truth — Prisma is still the migration tool
- The goal is zero Prisma code at runtime, not zero Prisma in the project
- `prisma-generator-drizzle` is a devDependency codegen tool, not a runtime dependency
