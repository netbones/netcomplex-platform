### 1. Create `src/app/api/admin/urgency/route.ts`

GET endpoint. Returns urgency counts for the command bar reactive CTAs and domain badge numbers.

**Auth pattern:** Use `requireAnyPermission(['admin', 'settings'])` from `@api/auth-utils`.
This gates access to ADMIN (has `admin` permission) plus BOARD, MANAGER, and COMMITTEE (have
`settings` permission). This is broader than the existing `page-flags/route.ts` pattern (which
checks `role !== 'ADMIN'` only) because the urgency/activity data serves anyone with management
responsibilities, not just full admins. If the auth check returns a NextResponse, return it
immediately (it's either 401 or 403). Use `withTenant()` from `@entities/tenant/api/with-tenant`
for tenantId.

```typescript
import { requireAnyPermission } from '@api/auth-utils';

// Inside the GET handler:
const authError = await requireAnyPermission(['admin', 'settings']);
if (authError) return authError;
const { tenantId } = await withTenant();
```

**Imports:** Tables from `@shared/api/db` (db, maintenanceRequests, groupMembershipRequests,
surveys, announcements, contents, competitions). Drizzle helpers `count, eq, and, lte` from
`drizzle-orm` directly (not re-exported from db.ts).

Add `export const maxDuration = 8;` at top.

Run these 6 counts in parallel with `Promise.all` (never sequential):

```typescript
const [
  openMaintenance,
  pendingMembers,
  closingSurveys,
  expiredAnnouncements,
  unpublishedContent,
  draftCompetitions,
] = await Promise.all([
  // Open maintenance requests (SUBMITTED status)
  db
    .select({ count: count() })
    .from(maintenanceRequests)
    .where(
      and(eq(maintenanceRequests.tenantId, tenantId), eq(maintenanceRequests.status, 'SUBMITTED'))
    ),

  // Pending group membership requests
  db
    .select({ count: count() })
    .from(groupMembershipRequests)
    .where(
      and(
        eq(groupMembershipRequests.tenantId, tenantId),
        eq(groupMembershipRequests.status, 'PENDING')
      )
    ),

  // Active surveys closing within 3 days
  db
    .select({ count: count() })
    .from(surveys)
    .where(
      and(
        eq(surveys.tenantId, tenantId),
        eq(surveys.status, 'ACTIVE'),
        lte(surveys.endDate, new Date(Date.now() + 3 * 24 * 60 * 60 * 1000))
      )
    ),

  // Announcements past their expiresAt
  db
    .select({ count: count() })
    .from(announcements)
    .where(and(eq(announcements.tenantId, tenantId), lte(announcements.expiresAt, new Date()))),

  // Content drafts not yet published
  db
    .select({ count: count() })
    .from(contents)
    .where(and(eq(contents.tenantId, tenantId), eq(contents.published, false))),

  // Competitions in DRAFT status
  db
    .select({ count: count() })
    .from(competitions)
    .where(and(eq(competitions.tenantId, tenantId), eq(competitions.status, 'DRAFT'))),
]);
```

Extract counts from each result (Drizzle count returns `[{ count: N }]`):

```typescript
const extractCount = (result: { count: number }[]) => result[0]?.count ?? 0;
```

Return shape:

```typescript
{
  commandBar: {
    openMaintenance: number,
    pendingMembers: number,
    closingSurveys: number,
    expiredAnnouncements: number,
  },
  domainBadges: {
    users: number,           // pendingMembers count
    maintenance: number,     // openMaintenance count
    content: number,         // unpublishedContent count
    events: number,          // 0 for now (future: events needing attention)
    competitions: number,    // draftCompetitions count
    resources: number,       // 0 for now (future: draft resources)
    surveys: number,         // closingSurveys count
    announcements: number,   // expiredAnnouncements count
    system: number,          // always 0
  }
}
```

Wrap in try/catch, return `NextResponse.json({ error: String(error) }, { status: 500 })` on failure.
Use `createComponentLogger` from `@shared/lib` for logging (same pattern as page-flags API).

### 2. Create `src/app/api/admin/activity/route.ts`

GET endpoint. Returns a paginated activity feed assembled from recent records across domain
tables. Same auth pattern as urgency route: `requireAnyPermission(['admin', 'settings'])` from
`@api/auth-utils`.

**Imports:** Same as urgency route plus `lt, desc, inArray, sql` from `drizzle-orm`. Tables:
`db, maintenanceRequests, users, contents, surveys, events` from `@shared/api/db`.

Add `export const maxDuration = 8;` at top.

Query params:

- `?domain=all|users|maintenance|content|events|surveys|system` (default: all)
- `?limit=20` (default: 20, max: 50)
- `?cursor=<ISO timestamp>` (for pagination — return items older than cursor)

**IMPORTANT: Platform admin handling.** Check `session.user.isPlatformAdmin` by querying the
`users` table for the current user's `isPlatformAdmin` field. If true AND a `?tenantId=<id>` query
param is provided, use that tenantId instead of `withTenant()`. This allows platform admins to
view cross-tenant activity. If no tenantId param, use the current tenant as normal.

**IMPORTANT: `sql<null>` is invalid TypeScript.** Use `sql<string | null>` for nullable actor IDs, or cast with `.then()`:

Build the feed by querying each relevant table for recent records, tagging each with a domain and
action label, then unioning, sorting, and paginating:

```typescript
// Internal type for query results before actor resolution
interface ActivityItemRaw {
  id: string;
  domain: string;
  action: string;
  resourceLabel: string | null;
  actorId: string | null;
  createdAt: Date;
  metadata: unknown;
}

// Build per-domain queries conditionally based on domain filter
const domainQueries: Promise<ActivityItemRaw[]>[] = [];

if (domain === 'all' || domain === 'maintenance') {
  domainQueries.push(
    db
      .select({
        id: maintenanceRequests.id,
        domain: sql<string>`'maintenance'`,
        action: sql<string>`
          CASE status
          WHEN 'SUBMITTED' THEN 'submitted'
          WHEN 'IN_PROGRESS' THEN 'started'
          WHEN 'COMPLETED' THEN 'completed'
          WHEN 'CANCELLED' THEN 'cancelled'
          ELSE 'updated'
          END
        `,
        resourceLabel: maintenanceRequests.description,
        actorId: maintenanceRequests.userId,
        createdAt: maintenanceRequests.updatedAt,
        metadata: sql<string>`json_build_object(
          'status', status,
          'category', category,
          'priority', priority
        )`,
      })
      .from(maintenanceRequests)
      .where(
        and(
          eq(maintenanceRequests.tenantId, tenantId),
          cursor ? lt(maintenanceRequests.updatedAt, new Date(cursor)) : undefined
        )
      )
      .orderBy(desc(maintenanceRequests.updatedAt))
      .limit(limit)
      .then(rows => rows.map(r => ({ ...r, domain: 'maintenance' as const })))
  );
}

if (domain === 'all' || domain === 'users') {
  domainQueries.push(
    db
      .select({
        id: users.id,
        domain: sql<string>`'users'`,
        action: sql<string>`'joined'`,
        resourceLabel: users.name,
        actorId: users.id,
        createdAt: users.createdAt,
        metadata: sql<string>`json_build_object('role', role, 'email', email)`,
      })
      .from(users)
      .where(
        and(
          eq(users.tenantId, tenantId),
          cursor ? lt(users.createdAt, new Date(cursor)) : undefined
        )
      )
      .orderBy(desc(users.createdAt))
      .limit(limit)
      .then(rows => rows.map(r => ({ ...r, domain: 'users' as const })))
  );
}

if (domain === 'all' || domain === 'content') {
  domainQueries.push(
    db
      .select({
        id: contents.id,
        domain: sql<string>`'content'`,
        action: sql<string>`CASE WHEN published THEN 'published' ELSE 'drafted' END`,
        resourceLabel: sql<string>`title->>'en'`, // extract English title from jsonb
        actorId: contents.authorId,
        createdAt: contents.updatedAt,
        metadata: sql<string>`json_build_object('category', category, 'published', published)`,
      })
      .from(contents)
      .where(
        and(
          eq(contents.tenantId, tenantId),
          cursor ? lt(contents.updatedAt, new Date(cursor)) : undefined
        )
      )
      .orderBy(desc(contents.updatedAt))
      .limit(limit)
      .then(rows => rows.map(r => ({ ...r, domain: 'content' as const })))
  );
}

if (domain === 'all' || domain === 'surveys') {
  domainQueries.push(
    db
      .select({
        id: surveys.id,
        domain: sql<string>`'surveys'`,
        action: sql<string>`
          CASE status
          WHEN 'ACTIVE' THEN 'activated'
          WHEN 'CLOSED' THEN 'closed'
          ELSE 'updated'
          END
        `,
        resourceLabel: surveys.title,
        actorId: sql<string | null>`null`,
        createdAt: surveys.updatedAt,
        metadata: sql<string>`json_build_object('status', status)`,
      })
      .from(surveys)
      .where(
        and(
          eq(surveys.tenantId, tenantId),
          cursor ? lt(surveys.updatedAt, new Date(cursor)) : undefined
        )
      )
      .orderBy(desc(surveys.updatedAt))
      .limit(limit)
      .then(rows => rows.map(r => ({ ...r, domain: 'surveys' as const })))
  );
}

if (domain === 'all' || domain === 'events') {
  domainQueries.push(
    db
      .select({
        id: events.id,
        domain: sql<string>`'events'`,
        action: sql<string>`'updated'`,
        resourceLabel: events.title,
        actorId: sql<string | null>`null`,
        createdAt: events.updatedAt,
        metadata: sql<string>`json_build_object('date', date, 'location', location)`,
      })
      .from(events)
      .where(
        and(
          eq(events.tenantId, tenantId),
          cursor ? lt(events.updatedAt, new Date(cursor)) : undefined
        )
      )
      .orderBy(desc(events.updatedAt))
      .limit(limit)
      .then(rows => rows.map(r => ({ ...r, domain: 'events' as const })))
  );
}

// Run all domain queries in parallel
const results = await Promise.all(domainQueries);

// Flatten, sort by createdAt desc, slice to limit
const feed = results
  .flat()
  .sort((a, b) => new Date(b.createdAt).getTime() - new Date(a.createdAt).getTime())
  .slice(0, limit);

// Fetch actor names in one batch query (avoid N+1)
const actorIds = [...new Set(feed.map(f => f.actorId).filter(Boolean))] as string[];
const actors =
  actorIds.length > 0
    ? await db
        .select({ id: users.id, name: users.name })
        .from(users)
        .where(inArray(users.id, actorIds))
    : [];
const actorMap = Object.fromEntries(actors.map(a => [a.id, a.name]));

// Attach actor names + derive next cursor
const items = feed.map(f => ({
  ...f,
  actorName: f.actorId ? (actorMap[f.actorId] ?? 'Unknown') : null,
  metadata: typeof f.metadata === 'string' ? JSON.parse(f.metadata) : f.metadata,
}));

const nextCursor = items.length === limit ? items[items.length - 1].createdAt.toISOString() : null;

return NextResponse.json({ items, nextCursor });
```

doesn't cache admin data). This is an admin-only endpoint — do NOT use unstable_cache (it's
user-session-specific data).

function formatRelativeTime(dateStr: string): string {
  const seconds = Math.floor((Date.now() - new Date(dateStr).getTime()) / 1000);
  if (seconds < 60) return 'just now';
  const minutes = Math.floor(seconds / 60);
  if (minutes < 60) return `${minutes}m ago`;
  const hours = Math.floor(minutes / 60);
  if (hours < 24) return `${hours}h ago`;
  const days = Math.floor(hours / 24);
  if (days < 7) return `${days}d ago`;
  return new Date(dateStr).toLocaleDateString();
}
