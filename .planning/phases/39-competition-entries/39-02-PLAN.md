  <action>
    Create `src/server/routers/competitions.ts` with the following tRPC procedures.

    Follow the pattern from `identity.ts` — use `router`, `publicProcedure`, `protectedProcedure`, `adminProcedure` from `@api/trpc/server`.

    Always:
    - Define `.input()` with Zod schemas
    - Define `.output()` with DTOs (never raw ORM)
    - Define `.meta({ openapi })` with method, path, tags, summary, protect
    - Use `TRPCError` for errors
    - Resolve tenant from `ctx.tenantId` (already in tRPC context)
    - Use DTOs from `@shared/api/dto/competition`

    **Procedure list:**

    1. `listPublicCompetitions` (publicProcedure — no auth required)
    - Method: GET, path: `/competitions/public`
    - Input: `z.object({}).optional()`
    - Output: `z.array(CompetitionDTO.extend({ participantCount: z.number(), topParticipants: z.array(ParticipantDTO).optional() }))`
    - Logic: Query competitions where status=ACTIVE, startDate<=now, endDate>=now, tenant scoped. For each, count JOINED entries and include up to 3 recent participant avatars. Uses existing `withTenant()` from request headers.

    2. `getCompetitionDetail` (publicProcedure)
    - Method: GET, path: `/competitions/{id}`
    - Input: `z.object({ id: z.string() })`
    - Output: CompetitionDTO with all fields + participantCount + participant avatars
    - Logic: Fetch single competition by ID, tenant scoped, include entry count and top participants.

    3. `joinCompetition` (protectedProcedure)
    - Method: POST, path: `/competitions/{id}/join`
    - Input: `z.object({ competitionId: z.string() })`
    - Output: `ParticipantDTO`
    - Logic:
      - Fetch competition, verify status=ACTIVE and type=RAFFLE
      - Verify current date is within startDate/endDate
      - Check maxParticipants limit if set
      - Check user hasn't already joined
      - Create CompetitionEntry with status=JOINED
      - Increment competition.entryCount
      - Return the entry as ParticipantDTO

    4. `submitPhotoEntry` (protectedProcedure)
    - Method: POST, path: `/competitions/{id}/entries`
    - Input: SubmitEntryInput
    - Output: `ParticipantDTO`
    - Logic: Same as joinCompetition but creates entry with submissionUrl/submissionText for PHOTO type. Validate photo URL is provided (required for PHOTO).

    5. `listParticipants` (protectedProcedure — admin only via adminProcedure or permission check)
    - Method: GET, path: `/competitions/{id}/participants`
    - Input: `z.object({ competitionId: z.string() })`
    - Output: `z.object({ participants: z.array(ParticipantDTO), total: z.number() })`
    - Logic: List all CompetitionEntry for a competition, joined with user table for name/avatar. Admin only (check role or use adminProcedure).

    6. `updateEntry` (protectedProcedure — admin only)
    - Method: PATCH, path: `/competitions/entries/{entryId}`
    - Input: UpdateEntryInput
    - Output: `ParticipantDTO`
    - Logic: Update entry score, status, or prize. Admin only.

    7. `markWinner` (protectedProcedure — admin only)
    - Method: POST, path: `/competitions/entries/{entryId}/winner`
    - Input: MarkWinnerInput
    - Output: `ParticipantDTO`
    - Logic:
      - Set entry status=WINNER, winnerAt=new Date(), prize from input
      - Create a Notification record via db.insert(notifications) for the winner user
        - title: "You won!"
        - message: `Congratulations! You won {competitionTitle}.`
        - type: "competition-winner"
        - link: `/competition/{competitionId}`
        - tenantId: ctx.tenantId
        - userId: entry.userId

    8. `drawWinners` (protectedProcedure — admin only)
    - Method: POST, path: `/competitions/{id}/draw`
    - Input: DrawWinnersInput
    - Output: `z.array(ParticipantDTO)`
    - Logic:
      - Fetch all JOINED entries for the competition
      - Randomly select `count` entries (Fisher-Yates shuffle on client) — use `Math.random()`
      - Mark each as WINNER with winnerAt and prize
      - Create Notifications for each winner
      - Return updated entries

    9. `listWinners` (publicProcedure)
    - Method: GET, path: `/competitions/{id}/winners`
    - Input: `z.object({ competitionId: z.string() })`
    - Output: `z.array(WinnerDTO)`
    - Logic: Fetch all entries with status=WINNER or RUNNER_UP, joined with users for name/avatar. Tenant scoped. Public (no auth required).

    Note: For OpenAPI, use OpenAPI-safe Zod schemas only (no z.any, no unsafe transforms). Path params should match the `path` in meta.

    Import DTOs from `@shared/api/dto/competition`. For the notification creation, use `db.insert(notifications)` with the notification schema available from `@api/db`.
