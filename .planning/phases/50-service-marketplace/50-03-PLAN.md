    **PATCH handler** — Update booking status:
    - Auth + tenant
    - Validate status transition (allowed: PENDING_CONFIRMATION → CONFIRMED, PENDING_CONFIRMATION → CANCELLED, CONFIRMED → COMPLETED, CONFIRMED → CANCELLED)

    - Query existing serviceBookings for this listing for the next 30 days (status != 'CANCELLED')
    - Return `{ availability: WeeklySchedule, bookedSlots: BookedSlot[] }` where `BookedSlot = { date, startTime, endTime }`
    - Days with empty arrays in availability JSONB → no slots available that day of week
