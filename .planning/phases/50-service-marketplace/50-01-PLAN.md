## Trust Boundaries

| Boundary                 | Description                                        |
| ------------------------ | -------------------------------------------------- |
| Notification insert → DB | User-supplied field values (title, message) stored |
| Email template → Resend  | HTML content sent to external email service        |

## STRIDE Threat Register

| Threat ID | Category               | Component                | Disposition | Mitigation Plan                                                                                                                                                      |
| --------- | ---------------------- | ------------------------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-50-01   | Spoofing               | notification-triggers.ts | mitigate    | recipientUserId always sourced from authenticated session or trusted DB record, never from client request                                                            |
| T-50-02   | Tampering              | notification-triggers.ts | mitigate    | payload JSON is server-constructed; listingId/bookingId sourced from DB queries, not request body                                                                    |
| T-50-03   | Information Disclosure | marketplace-templates.ts | accept      | Email templates contain service metadata (already public on listing page); no PII beyond booking date/time                                                           |
| T-50-04   | Elevation of Privilege | platform-flags.ts        | mitigate    | marketplacePaypal flag is DB-backed, resolved server-side; canAccess() gate prevents unauthorized enable                                                             |
