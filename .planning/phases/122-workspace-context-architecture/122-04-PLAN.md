## Trust Boundaries

| Boundary                           | Description                                                                                                                                                       |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Selector rows → switchWorkspace    | The selector renders workspace rows derived from the registry + RLS-gated delegations; clicking a row triggers switchWorkspace which re-resolves authoritatively. |
| Recent/Pinned prefs ↔ localStorage | User-controlled preference snapshot persisted client-side; holds NO PII beyond workspace labels and scope refs.                                                   |

## STRIDE Threat Register

| Threat ID | Category               | Component                                            | Severity | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                                                                                              |
| --------- | ---------------------- | ---------------------------------------------------- | -------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| T-122-12  | Information Disclosure | useWorkspaceRecentStore / PinnedStore (localStorage) | low      | mitigate    | Prefs snapshots hold ONLY `{workspaceId, workspaceType, label, scope}` — NOT `permissions[]` (R-09). The Guard test asserts no `permissions` key in serialized stored entries, so capability data never persists to localStorage where another script-origin could read it. scope refs (propertyId/providerId) are opaque IDs, not PII (no delegator names). |
| T-122-13  | Elevation of Privilege | WorkspaceSelector row click                          | low      | mitigate    | Clicking a row passes a `WorkspaceTarget` to `switchWorkspace`; authorization is re-done in `resolveWorkspaceContext` against RLS-gated delegations (T-122-04/05). A row that was rendered from a now-revoked delegation will fail resolve → rollback (P-03) + error toast, no navigation. The selector is NOT an authorization surface.                     |
| T-122-14  | Tampering              | localStorage soralia:workspace-tree-expanded         | low      | accept      | Expand/collapse state is purely cosmetic; tampering only changes which subtrees are collapsed — no auth/permission impact.                                                                                                                                                                                                                                   |
