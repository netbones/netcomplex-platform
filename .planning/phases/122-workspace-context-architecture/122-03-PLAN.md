## Trust Boundaries

| Boundary                                 | Description                                                                                                                                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Notification deep-link → switchWorkspace | An in-app or external link can carry a resource URL that triggers an automatic workspace switch. The link itself is untrusted; only RLS-gated delegation resolution authorizes the switch. |
| WorkspaceContext ↔ GateContext           | Two hooks coexist; switching must NOT alter role/flags (C-04).                                                                                                                             |

## STRIDE Threat Register

| Threat ID | Category               | Component                                | Severity | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------- | ---------------------- | ---------------------------------------- | -------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-122-08  | Tampering              | inferWorkspaceTarget / NotificationLink  | medium   | mitigate    | `inferWorkspaceTarget` only PARSes the URL structure into a target descriptor — it grants NOTHING. Authorization happens in `resolveWorkspaceContext` against RLS-gated delegations (T-122-04/05). A malicious `/properties/{victimPropertyId}` link will throw `registry_miss` because the victim delegation is not in the caller's RLS-scoped delegation list → switchWorkspace rolls back (P-03), error toast fires, NO navigation (UI-SPEC failure row). Verified by NotificationLink test: clicking a revoked/unauthorized link does not navigate. |
| T-122-09  | Information Disclosure | Pino observability in switchWorkspace    | medium   | mitigate    | switchWorkspace emits `workspace.switch.attempt/success/failed` with `from/to workspaceId`, `workspaceType`, `trigger`, `durationMs`, `reason` only (UI-SPEC §Observability). NEVER log `permissions[]` (capability data) or delegator PII (`grantedByName`, `propertyAddress`). Verified by `rg` of the switch file asserting no permissions/PII log fields; property test asserts the log field set never contains PII keys.                                                                                                                          |
| T-122-10  | Elevation of Privilege | switchWorkspace rollback failure         | high     | mitigate    | If `setCtx(nextCtx)` could fire before resolve completes, a half-context could grant partial access. Mitigation: `setCtx` is called ONLY after `resolveWorkspaceContext` returns successfully (Step 2 strictly after Step 1 success — Pattern E). On any throw, the prior context remains. P-03 property test asserts prior context identity unchanged after a failing switch.                                                                                                                                                                          |
| T-122-11  | Repudiation            | External deep-link middleware (deferred) | low      | accept      | External/email deep-link middleware hint-header flow (`?agent_token` strip + read-once `x-workspace-hint`) is OUT of P1a scope per VALIDATION Test Sequencing item 4. No package-legitimacy gate needed this plan.                                                                                                                                                                                                                                                                                                                                                                                       |
