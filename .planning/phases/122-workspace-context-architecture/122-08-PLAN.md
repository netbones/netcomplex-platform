Import `WorkspaceScopePanel` from `@widgets/workspace` at the top of SpaceChrome.tsx alongside the existing imports. Render `<WorkspaceScopePanel />` as a persistent element between the SpaceLauncher sidebar and the main content area.

    The panel reads `useWorkspaceContext()` internally and handles all rendering states:
    - **Null context (resolving):** renders `<LoadingSkeleton />` (existing shared primitive)
    - **AUTOMATION workspaceType:** returns `null` (D-11 — never renders)
    - **PERSONAL/PROVIDER/PROPERTY/OWNER:** renders type-specific identity fields per UI-SPEC §Surface 3

    Placement strategy — render as a thin identity strip above `<main>` content, between the sidebar and main, so it's visible on every dashboard page without consuming sidebar real estate:

    ```tsx
    <div className="flex min-h-screen bg-gray-50">
      <SpaceLauncher ... />

      {/* Workspace identity bar + main content column */}
      <div className="flex flex-col flex-1 min-w-0">
        <WorkspaceScopePanel />
        <main
          className="flex-1 min-w-0 md:pb-0"
          style={{ paddingBottom: 'calc(4rem + env(safe-area-inset-bottom, 0px))' }}
        >
          <EmptyWorkspaceState />
          {children}
        </main>
      </div>
    </div>
    ```

    Note: This restructures the layout from `sidebar + main` to `sidebar + (identity-bar + main column)`. The `<main>` element is wrapped in a column flex container that also holds the WorkspaceScopePanel. On mobile, the panel collapses gracefully — the MobileSpaceBar handles primary navigation.

    The WorkspaceScopePanel component was built and tested in plan 122-06 (20 parametrized tests GREEN). It reads `WORKSPACE_REGISTRY` for type labels, `useDelegations()` for delegator/expiry data, and `SCOPE_LABELS` for permission chip labels. SpaceChrome needs zero awareness of workspace state — just import and render.

    This plan touches ONLY SpaceChrome.tsx. The component files themselves are unchanged. The EmptyWorkspaceState import from plan 122-07 is preserved — the WorkspaceScopePanel and EmptyWorkspaceState coexist in the same layout.
