  <action>
    Create three route files:

    **1. `questions/route.ts`** — GET + POST:

    **GET**: Fetch all questions for a survey, ordered by `sectionId` then `order`.
    ```typescript
    return apiSuccess(questions);
    ```

    **POST**: Create a new question.
    - Accept body: `{ text, type, options?, required?, order?, sectionId?, config? }`
    - If `order` is not provided, auto-set to max existing order + 1
    - Validate `type` is a valid QuestionType value
    - If `type` is SINGLE_CHOICE or MULTIPLE_CHOICE and no `options`, default to `["Option 1"]`
    - Return `apiCreated(question)`

    **2. `questions/reorder/route.ts`** — POST:
    - Accept body: `{ items: [{ id: string, order: number, sectionId?: string }] }`
    - Use `db.transaction` to update each question's order and sectionId in a batch
    - Return `apiSuccess({ reordered: items.length })`

    **3. `questions/[questionId]/route.ts`** — PATCH + DELETE:

    **PATCH**: Update question fields (text, type, options, required, order, sectionId, config).
    - Return `apiSuccess(updatedQuestion)`

    **DELETE**: Delete a question.
    - Return `apiNoContent()`

    All routes use the canonical response envelope. Import auth, db, tables from existing patterns. Add tenant scoping via `withTenant()`.
  </action>
