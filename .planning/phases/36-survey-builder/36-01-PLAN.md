  <files>

  <action>
    Apply the following changes to `prisma/schema.prisma`:

    1. **QuestionType enum** — Add `LINEAR_SCALE` to the enum:
       ```prisma
       enum QuestionType {
         SINGLE_CHOICE
         MULTIPLE_CHOICE
         TEXT
         RATING
         YES_NO
         LINEAR_SCALE
       }
       ```

    2. **Question model** — Add `config` JSON column and optional `sectionId` FK:
       ```prisma
       model Question {
         id        String       @id
         tenantId  String
         surveyId  String
         sectionId String?
         text      String
         type      QuestionType
         options   String[]
         required  Boolean      @default(false)
         order     Int          @default(0)
         config    Json?        @default("{}")
         Survey    Survey       @relation(fields: [surveyId], references: [id], onDelete: Cascade)
         Section   SurveySection? @relation(fields: [sectionId], references: [id], onDelete: SetNull)

         @@index([surveyId])
         @@index([sectionId])
       }
       ```

    3. **Survey model** — Add `config` JSON column for metadata tags:
       ```prisma
       model Survey {
         id          String       @id
         tenantId    String
         title       String
         description String?
         type        SurveyType   @default(INTERNAL)
         status      SurveyStatus @default(DRAFT)
         startDate   DateTime?
         endDate     DateTime?
         config      Json?        @default("{}")
         createdAt   DateTime     @default(now())
         updatedAt   DateTime     @default(now()) @updatedAt
         Question    Question[]
         Response    Response[]
         Section     SurveySection[]
       }
       ```

    4. **New model: SurveySection** — Add between Survey and existing models:
       ```prisma
       model SurveySection {
         id          String    @id
         tenantId    String
         surveyId    String
         title       String?
         description String?
         image       String?
         order       Int       @default(0)
         createdAt   DateTime  @default(now())
         updatedAt   DateTime  @default(now()) @updatedAt
         Survey      Survey    @relation(fields: [surveyId], references: [id], onDelete: Cascade)
         Question    Question[]

         @@index([surveyId])
       }
       ```

    Do NOT modify any other models or enums. Use `@default("{}")` for Json fields so existing rows get a default value. Keep all existing indexes and relations.
  </action>
