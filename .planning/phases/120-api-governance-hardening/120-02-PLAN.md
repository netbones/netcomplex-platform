## CONTEXT.md Override Note

**D-01 Override (envelope at middleware level):** CONTEXT.md D-01 specifies envelope wrapping at the tRPC middleware layer. This is technically infeasible in tRPC v11 — no success-response transformation middleware exists. The per-procedure `toEnvelope()` approach applied throughout this plan follows the tRPC v11 constraint confirmed in RESEARCH.md §Alternatives Considered (line 52) and Plan 01 rationale block. All procedure returns use `toEnvelope(data)` per-procedure rather than a non-existent middleware hook.
</rationale>

The identity router (1835 lines) is the most PII-dense router in the system, exposing user profiles, properties, household members, albums, and seat assignments.

| Threat ID   | Category               | Component            | Severity | Disposition | Mitigation Plan                                                                                                                                          |
| ----------- | ---------------------- | -------------------- | -------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-120-02-01 | Information Disclosure | propertyDto, userDto | high     | mitigate    | DTO `.pick()` only exposes safe fields; inline `profileSchema`/`userSchema` deleted and replaced with DTOs that exclude PII-sensitive columns            |
| T-120-02-02 | Elevation of Privilege | identity.ts tiers    | high     | mitigate    | adminProcedure → privilegedProcedure migration ensures COMMITTEE role is included; inline tenantId checks removed in favor of tenantProcedure middleware |
| T-120-02-03 | Spoofing               | tenantProcedure      | medium   | mitigate    | tenantProcedure middleware enforces non-null ctx.tenantId; cross-tenant property access prevented at middleware layer rather than per-procedure          |
| T-120-02-04 | Information Disclosure | albumDto, seatDto    | medium   | mitigate    | Album and seat DTOs use drizzle-zod `.pick()` to expose only safe fields; premium seat financial details restricted to privileged procedures             |

</threat_model>
