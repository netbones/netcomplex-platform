    Append ADR-018 before the "_More ADRs will be added..." footer. Document:

    **Title:** ADR-018: Unify on Sonner for Toast Notifications

    **Context:** Three competing toast systems existed: Sonner (direct + useApiToast wrapper), custom Zustand ToastProvider, and useApiToast hook. This caused dual rendering (Sonner top-right + Zustand bottom-right), inconsistent features, and maintenance burden.

    **Decision:** Sonner is the single toast system. useApiToast remains as the preferred hook for API operations (adds retry, server logging, promise handling). Zustand Toast is removed.

    **Consequences:**
    - Positive: Single rendering engine, consistent positioning (top-right), useApiToast provides retry/logging for API calls, reduced bundle size
    - Negative: Zustand toast's duplicate prevention lost (Sonner doesn't dedup by default — acceptable trade-off)

    **Migration:**
    - Remove src/shared/ui/Toast.tsx
    - Remove ToastProvider from providers.tsx
    - Migrate admin/users page from useToast() to direct toast.* calls
    - Remove dead useToast import from sign-up page

  </action>
