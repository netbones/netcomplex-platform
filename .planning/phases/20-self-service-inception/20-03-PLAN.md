<objective>
Add time-limited staff access mechanism (AssistSession) for assisted provisioning (Path B).

Purpose: For enterprise clients requiring white-glove onboarding, NetComplex staff need temporary, scoped access to help set up the tenant. This must be strictly bounded: time-limited, logged, revocable by the tenant owner, and scoped to metadata only — never tenant content, users, or settings. This replaces the trust boundary violation from v1 where Platform Admin had standing ADMIN access.

Output: AssistSession model, API routes for create/revoke, and auth-guard integration.
</objective>

  <action>
    Create API routes for assist session management:

    **POST /api/admin/platform/assist** — Create assist session:
    - Require isPlatformAdmin=true (check via auth session)
    - Accept: { tenantId, expiresAt (optional, default 7 days), notes (optional) }
    - Validate tenantId exists
    - Create AssistSession with: staffId=session.user.id, scope="metadata", expiresAt, isActive=true
    - Return: { sessionId, expiresAt }

    **GET /api/admin/platform/assist** — List active sessions:
    - Require isPlatformAdmin=true
    - Return all active (non-expired, non-revoked) assist sessions
    - Filter by optional ?tenantId query param

    **DELETE /api/admin/platform/assist/[id]** — Revoke assist session:
    - Require: either isPlatformAdmin=true OR user is the tenant owner (tenant.ownerId === session.user.id)
    - Set isActive=false, revokedAt=now(), revokedBy=session.user.id
    - Return: { success: true }

    **PATCH /api/admin/platform/assist/[id]/extend** — Extend session:
    - Require isPlatformAdmin=true
    - Accept: { expiresAt: new date }
    - Update expiresAt on the session
    - Return: { expiresAt }

    All routes must check isPlatformAdmin via the auth session. Use the existing auth pattern from the tenant routes.
