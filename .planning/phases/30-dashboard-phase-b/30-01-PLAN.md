<name>Task 1: Define space model and visibility logic</name>
<files>src/widgets/dashboard/model/spaces.ts, src/widgets/dashboard/model/types.ts</files>
<action>
Create `src/widgets/dashboard/model/spaces.ts` with:

1. **SpaceDefinition interface** — each space has:
   - `id: string` — URL slug (home, services, community, messages, admin)
   - `labelKey: string` — i18n key for display name
   - `icon: LucideIcon` — from lucide-react (Home, Briefcase, Users, MessageSquare, Shield)
   - `isCore: boolean` — core spaces (home, messages, admin) are always visible; optional spaces (services, community) auto-hide when feature flags disable all their widgets
   - `requiredFlag?: keyof PlatformPageFlags` — feature flag that gates this space's visibility (only for optional spaces). services → 'services', community → null (community is always shown for now since events/groups/surveys/competitions flags are independent — community auto-hides only if ALL its sub-flags are off)
   - `minimumRole?: string` — 'admin' for admin space, undefined for all others
   - `widgetIds: string[]` — which widget IDs belong to this space (used by AddWidgetModal filtering)

2. **SPACES constant** — the 5-space model per user decisions:
   - `home` — isCore: true, widgetIds: ['stats', 'quick-actions', 'recent-activity', 'notifications']
   - `services` — isCore: false, requiredFlag: 'services', widgetIds: ['maintenance-requests', 'maintenance-list', 'maintenance-analytics', 'my-services', 'service-inquiries']
     NOTE: Maintenance merged under Services per user Q1 decision
   - `community` — isCore: false, widgetIds: ['events', 'announcements-stream', 'my-content', 'my-album', 'media', 'bookshelf', 'admin-events', 'admin-surveys', 'group-moderation', 'admin-announcements', 'admin-competitions', 'admin-resources', 'admin-content']
   - `messages` — isCore: true, widgetIds: ['messages', 'notifications']
   - `admin` — isCore: true, minimumRole: 'admin', widgetIds: ['admin-stats', 'admin-activity', 'admin-quick-links', 'admin-user', 'admin-system', 'page-settings']

3. **SPACE_SLUGS** — `Object.keys(SPACES)` as const for route validation

4. **getVisibleSpaces(role: string, flags: PlatformPageFlags): SpaceDefinition[]** — returns spaces visible for given role + flags:
   - Filter out admin space if role is not admin/board
   - Filter out optional spaces if their requiredFlag is false
   - For community space (no single requiredFlag): hide if ALL of events, groups, surveys, competitions, news flags are false (auto-hide per user Q2 hybrid decision)
   - Always include core spaces (home, messages, admin if role permits)

5. **Add `spaces?: SpaceId[]` optional field to WidgetManifest in types.ts** — not required yet, will be wired in plan 03. For now, just the type addition.

Do NOT modify any existing widget files, DashboardPage, or DashboardTabs. This plan only creates new files and the route structure.
