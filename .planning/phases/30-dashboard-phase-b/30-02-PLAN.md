<name>Task 1: Build HomeLayer three-zone component</name>
<files>src/widgets/dashboard/ui/HomeLayer.tsx</files>
<action>
Create `src/widgets/dashboard/ui/HomeLayer.tsx` — a client component with three zones:

**UrgencyZone (top):**

- Fetches GET /api/announcements?priority=urgent (or filter client-side) — shows urgent announcements as cards with left-border accent + priority pill
- Fetches GET /api/maintenance (resident: filter by userId, overdue status; admin: all overdue) — shows overdue maintenance count + link
- Shows unread message count with link to /dashboard/messages
- If nothing is urgent, renders nothing (zone collapses — no empty state header)
- Role-aware: resident sees their own overdue items; admin/board sees all

**TodayZone (middle):**

- Section header: "Today" with date
- Fetches bookings happening today (GET /api/bookings?date=today or equivalent)
- Fetches events happening today/tomorrow (GET /api/events?upcoming=true&limit=5, filter client-side for today/tomorrow)
- Pending actions: survey invitations, group membership requests (for admin) — lightweight card list
- Empty state: "Nothing scheduled for today" with muted text

**ActivityZone (bottom):**

- Section header: "Recent Activity"
- Renders a simplified version of RecentActivityWidget content — recent content, announcements, maintenance updates
- Fetches GET /api/announcements (non-urgent, limit 5) for community announcements
- Latest news/content items
- "My content" shortcut link for residents

**Implementation details:**

- Each zone is a separate sub-component within the file (UrgencyZone, TodayZone, ActivityZone)
- Loading states: skeleton cards per zone (not full-page spinner)
- Error states: error card per zone with retry button (not full-page error)
- Every item in every zone is either informational or a LINK into a space — no forms, no tables, no management UI
- Links use Next.js `<Link href="/dashboard/[space]">` pattern to navigate into spaces
- Style: white cards on gray-50 background, consistent with existing dashboard aesthetic
- Use authClient.useSession() for role/userId
- Responsive: single column on mobile, max-w-4xl on desktop

**Data fetching (per advisory A4 — explicit Promise.all pattern):**

- Use a SINGLE `useEffect` with `Promise.all` for all three zone fetches. Do NOT use the per-widget pattern of separate useEffect calls — that causes three sequential renders and a visible cascade of loading skeletons.
- Structure:
  ```ts
  useEffect(() => {
    Promise.all([
      fetch('/api/announcements?priority=urgent').then(r => (r.ok ? r.json() : [])),
      fetch('/api/maintenance?overdue=true').then(r => (r.ok ? r.json() : [])),
      fetch('/api/events?upcoming=true&limit=5').then(r => (r.ok ? r.json() : [])),
    ])
      .then(([announcements, maintenance, events]) => {
        setUrgent(announcements);
        setOverdue(maintenance);
        setEvents(events);
        setLoading(false);
      })
      .catch(() => setError(true));
  }, []);
  ```
- Use existing API routes (no new API routes needed for this plan)
- If an API returns 404/403, treat as empty data (feature may be disabled for tenant)

Do NOT create new API routes. Use existing ones only.
