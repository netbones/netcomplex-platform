   - Mock DB returns 2 settings

   - Mock DB returns settings array
   - Assert response is the full array

   - Mock admin session
   - Send `{ key: 'val' }`
   - Assert `writeAuditLog` called + `revalidateAdminChanges` called

7. **GET /contact returns key-value map**
   - Mock DB with 2 settings
   - Assert response is `{ key1: 'val1', key2: 'val2' }`
