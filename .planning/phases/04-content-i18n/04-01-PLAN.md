# Plan: Content i18n with TipTap Editor

## Overview

Add multilingual content support to NetComplex's CMS, allowing admins to create and manage content in multiple languages.

## Approaches

### Option A: Single Locale per Content (Simplest)

Each content item has ONE language. Admin creates separate content items per language.

```prisma
model Content {
  id          String          @id
  tenantId    String
  title       String
  content     String
  locale      String          @default("en")  // Single locale per item
  // ...
}
```

**Pros:** Simple, existing workflow, no editor changes
**Cons:** Duplication when content is similar across languages

---

### Option B: JSONB Locale Fields (Recommended)

Store all translations in JSONB columns. Admin can edit any language.

```prisma
model Content {
  id          String          @id
  tenantId    String
  title       Json            // { "en": "Title", "af": "Titel" }
  content     Json            // { "en": "<p>...</p>", "af": "<p>...</p>" }
  excerpt     Json?
  // ...
  defaultLocale String        @default("en")  // Fallback locale
}
```

**Pros:** Single content item, editor shows language tabs
**Cons:** More complex schema and UI

---

### Option C: Separate Locale Table

Normalized approach with separate ContentLocale table.

```prisma
model Content {
  id          String          @id
  tenantId    String
  defaultLocale String        @default("en")
  locales     ContentLocale[]
}

model ContentLocale {
  id          String   @id
  contentId   String
  locale      String   // "en", "af", etc.
  title       String
  content     String
  excerpt     String?
}
```

**Pros:** Clean normalization, easy queries per locale
**Cons:** More complex relationships, more JOINs

---

## Translation Sources

### 1. Manual Translation (Default)

- Admin writes each translation manually in TipTap
- TipTap extension provides language tabs/selector

### 2. AI Auto-Translate (Future Enhancement)

- "Translate" button in editor
- Calls translation API (DeepL, Google, OpenAI)
- Populates other locale fields
- Requires API key configuration

---

## Implementation Plan

### Phase 1: Schema Changes

Add locale support to Content model (Option B - JSONB):

```prisma
model Content {
  id              String   @id
  tenantId        String
  title           Json     // { "en": "...", "af": "..." }
  content         Json     // { "en": "...", "af": "..." }
  excerpt         Json?    // { "en": "...", "af": "..." }
  defaultLocale   String   @default("en")
  category        ContentCategory
  // ...
}
```

### Phase 2: TipTap Editor Extension

Create `LocaleSelector` extension for TipTap:

```typescript
// Custom TipTap extension that adds language tabs
import { Node } from '@tiptap/core';

const LocaleSelector = Node.create({
  name: 'localeSelector',
  // Renders language tabs in editor toolbar
  // Switches which locale field is being edited
});
```

Also adds:

- Language selector dropdown
- "Copy to [locale]" button
- "Auto-translate" button (future)

### Phase 3: Admin UI Updates

- Add language selector to content editor
- Show active language indicator
- Add "Add Translation" button
- Preview content in different locales

### Phase 4: API Updates

- Fetch content based on user locale
- Fallback to default locale if translation missing
- Store/update translations in JSONB fields

### Phase 5: Frontend Updates

- Pass user locale when fetching content
- Display content in user's preferred language
- Show language badge on content items
