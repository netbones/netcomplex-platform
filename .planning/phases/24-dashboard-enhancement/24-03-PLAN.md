<objective>
Fix widget state persistence so user's widget selections and layouts survive tab changes and page refreshes.

Purpose: The dashboard currently resets widgets to defaultWidgets on every tab change (handleTabChange calls setActiveWidgets(currentTab.defaultWidgets)). The zustand store already has persist middleware but the dashboard page ignores userWidgets from the store. This plan wires the dashboard to read/write userWidgets from the store.
Output: Updated dashboard page using store for widget state, store initialized with defaults from ADMIN_TABS.
</objective>
