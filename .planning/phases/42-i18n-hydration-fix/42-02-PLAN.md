<name>Task 1: Migrate messages domain page to useSafeTranslation</name>
<files>src/app/(tenant)/dashboard/messages/[domain]/page.tsx</files>
<action>
Replace `useTranslation` from react-i18next with `useSafeTranslation` from `@features/i18n/model/useTranslation`. Convert all `t()` calls that render visible text to `tx()` with English fallbacks.

Current pattern (line 5, 17):

```tsx
import { useTranslation } from 'react-i18next';
const { t } = useTranslation('common');
```

New pattern:

```tsx
import { useSafeTranslation } from '@features/i18n/model/useTranslation';
const { tx } = useSafeTranslation(['common', 'messages']);
```

Note: Load both `common` and `messages` namespaces upfront (same pattern as services page did with `['common', 'services']`) — this ensures the `messages` namespace is requested on first render rather than lazy-loading after hydration.

**Specific t() → tx() conversions (every visible text call):**

Line 34: `t('nav.home')` → `tx('nav.home', 'Home')`
Line 35: `t('nav.dashboard')` → `tx('nav.dashboard', 'Dashboard')`
Line 37-38: `t('spaces.messages', { defaultValue: 'Messages' })` → `tx('spaces.messages', 'Messages')`
Line 41: `t(domainDef?.labelKey ?? domain, { ns: 'messages' })` → `tx(domainDef?.labelKey ?? domain, domainDef?.id ? domainDef.id.charAt(0).toUpperCase() + domainDef.id.slice(1) : domain, { ns: 'messages' })`

Line 51-52: `t(domainDef?.labelKey ?? domain, { ns: 'messages' })` → same tx pattern as line 41
Line 55: `t(domainDef.descriptionKey, { ns: 'messages' })` → `tx(domainDef.descriptionKey, domainDef?.description ?? '', { ns: 'messages' })`

Line 63: `t('domains.back', { ns: 'messages', defaultValue: 'Back to Messages' })` → `tx('domains.back', 'Back to Messages', { ns: 'messages' })`

Line 83: `t(domainDef?.labelKey ?? domain, { ns: 'messages' })` → same tx pattern
Line 86-88: `t('domains.comingSoon', { ns: 'messages', defaultValue: 'This section is coming soon.' })` → `tx('domains.comingSoon', 'This section is coming soon.', { ns: 'messages' })`

**IMPORTANT:** When using `tx()` with a namespace other than the default (e.g., `{ ns: 'messages' }`), pass the ns in the options object: `tx('key', 'fallback', { ns: 'messages' })`. The `useSafeTranslation` hook's `tx()` method passes options through to `t()`.
</action>
