    B) Create src/shared/api/ai/pool.ts with these exports:

       b1) `getCurrentBillingMonth(): string`
           - Returns `YYYY-MM` string from `new Date()` in UTC
           - Simple: `const d = new Date(); return \`${d.getUTCFullYear()}-${String(d.getUTCMonth() + 1).padStart(2, '0')}\`;`

       b2) `getOrCreateUsage(tenantId: string, month: string, db: DrizzleDb): Promise<typeof tenantAiUsage.$inferSelect>`
           - Query tenantAiUsage where tenantId + billingMonth match
           - If found → return it
           - If not found → query PlatformAiTierQuota for tenant's tier, insert new TenantAiUsage with tokensAllotted = quota.monthlyTokens, return new record
           - Must be idempotent — calling twice returns the same record

       b3) `getTierQuota(tenantId: string, db: DrizzleDb): Promise<typeof platformAiTierQuota.$inferSelect>`
           - Read tenant's tier from tenants table
           - Read PlatformAiTierQuota for that tier
           - Return quota record (contains monthlyTokens, overagePolicy, overageTokens, overagePriceZAR)

       b4) `getCapabilityCost(capability: AiCapabilityKey, db: DrizzleDb): Promise<typeof aiCapabilityCost.$inferSelect>`
           - Query aiCapabilityCost where capability matches
           - Return cost record (contains estimatedTokens, maxTokens)

       b5) `checkQuota(tenantId: string, capability: AiCapabilityKey, db: DrizzleDb): Promise<{ allowed: boolean; denyReason?: 'quota_exhausted' | 'module_disabled'; remainingTokens: number }>`
           - Get current month usage via getOrCreateUsage
           - Get capability cost via getCapabilityCost
           - Get tier quota via getTierQuota
           - Calculate remaining = usage.tokensAllotted - usage.tokensUsed
           - If remaining <= 0:
             - If quota.overagePolicy === 'HARD_STOP' → return { allowed: false, denyReason: 'quota_exhausted', remainingTokens: 0 }
             - Otherwise (THROTTLE/SURCHARGE) → allow (policy enforced post-call)
           - If remaining < cost.estimatedTokens && quota.overagePolicy === 'HARD_STOP':
             - return { allowed: false, denyReason: 'quota_exhausted', remainingTokens: remaining }
           - Return { allowed: true, remainingTokens: remaining }

       b6) `recordUsage(options: PoolCallOptions & { provider: string; model: string; inputTokens: number; outputTokens: number; durationMs: number; success: boolean; errorCode?: string }, db: DrizzleDb): Promise<void>`
           - Interface PoolCallOptions: { tenantId: string; capability: AiCapabilityKey; userId?: string; referenceId?: string }
           - GetOrCreate current month usage
           - Calculate total = inputTokens + outputTokens
           - Calculate overage = max(0, (usage.tokensUsed + total) - usage.tokensAllotted)
           - Calculate overageCost = overage * Number(quota.overagePriceZAR)
           - In a DB transaction:
             a. Update tenantAiUsage: tokensUsed += total, overageTokens += overage, overageCostZAR += overageCost, updatedAt = now
             b. Insert AiUsageEvent with all fields
           - After the transaction, check 80% warning threshold:
             - If newUsed/allotted >= 0.8 AND previous (newUsed - total)/allotted < 0.8 → crossed 80% threshold
             - Create a Notification via db.insert(notifications) for all ADMIN-role users in the tenant
             - Title: "AI token quota at 80%"
             - Message includes percentage and month
           - Wrap the notification in try/catch — notification failure must not block usage recording

       per G5: Platform pool only. No tenant key lookup in pool.ts.
       per G9: overagePriceZAR = R0.0001/token for ENTERPRISE only.
       per D-G8: quota values from seed (STANDARD 50k, PREMIUM 200k, ENTERPRISE 500k).

    C) Add `import 'server-only';` at top — this module reads env vars and DB, must never be client-bundled.

## Trust Boundaries

| Boundary                           | Description                                                                                                     |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Env vars → getPoolProviderConfig() | PLATFORM_ANTHROPIC_KEY / PLATFORM_OPENAI_KEY read from process.env — must never be logged or returned to client |
| pool.ts → DB                       | recordUsage writes tenant usage counters — RLS dormant, app-level tenantId filter                               |

## STRIDE Threat Register

| Threat ID | Category               | Component                                                             | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                       |
| --------- | ---------------------- | --------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-104-04  | Information Disclosure | getPoolProviderConfig() reads platform keys from process.env          | mitigate    | Keys never interpolated into log strings, error messages, or API responses. provider.ts uses keys only to construct SDK clients — keys live in memory, never serialized. Add `// eslint-disable-next-line no-console` comment warning on any console.log of key-containing variables. |
| T-104-05  | Denial of Service      | checkQuota() — no rate limiting on quota checks                       | accept      | Quota check is a DB query — same cost as any Drizzle read. Rate limiting is handled at the API route level (existing rateLimitByKey/rateLimitByUser).                                                                                                                                 |
