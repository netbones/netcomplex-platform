      - Cast `module.config as AiProviderModuleConfig | null`

      - Call `isAiCapabilityEnabled(tenantId, capability)`
      - If false, throw `new Error(\`AI capability '\${capability}' is not enabled for this community\`)`
      - This is intentionally NOT a ModuleNotEnabledError — use plain Error for now (no existing error class fits)
