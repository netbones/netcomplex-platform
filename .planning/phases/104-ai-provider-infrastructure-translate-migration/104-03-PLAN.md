    per AI-PROV-01 (admin management surface for AI provider).

    All routes follow the same auth pattern:
    - Import `getSessionAndRole, apiSuccess, apiError` from `@api/server`
    - Import `withTenant, SETTINGS_KEYS` from `@entities/tenant/server`
    - Validate auth: `if (!auth) return apiError('UNAUTHORIZED', ...)`; `if (!['admin','board'].includes(auth.role)) return apiError('FORBIDDEN', ...)`
    - Use Zod for input validation

    **1. Create src/app/api/admin/ai-provider/status/route.ts — GET:**
    - Import `getSettingValue` from `@entities/tenant/server`
    - Call `withTenant()` to get tenantId
    - Check if encrypted keys exist in settings table (existence check only — never decrypt)
    - Check TenantModule.config for capabilities
    - Return: `apiSuccess({ anthropicConfigured, openaiConfigured, deepseekConfigured, defaultProvider, capabilities })`
    - `configured` = key exists in settings (not null/undefined). Key value NEVER returned.
    - `capabilities` = the `AiProviderModuleConfig.capabilities` from TenantModule.config, defaulting to empty object

    **2. Create src/app/api/admin/ai-provider/key/route.ts — POST:**
    - Zod schema: `z.object({ provider: z.enum(['anthropic','openai','deepseek']), key: z.string().min(1) })`
    - Call `withTenant()` for tenantId
    - Map provider to setting key: `provider === 'anthropic'` → `AI_ANTHROPIC_KEY`, etc.
    - Encrypt: `const encrypted = encryptKey(parsed.data.key)`
    - Store via `setSettingValue(tenantId, settingKey, encrypted)`
    - Return `apiSuccess({ stored: true })`
    - NEVER return or log the raw key

    **3. Create src/app/api/admin/ai-provider/delete/route.ts — DELETE:**
    - Zod schema: `z.object({ provider: z.enum(['anthropic','openai','deepseek']) })`
    - Call `withTenant()` for tenantId
    - Map provider to setting key
    - Call `deleteSettingValue(tenantId, settingKey)`
    - Return `apiSuccess({ deleted: true })`

    **4. Create src/app/api/admin/ai-provider/test/route.ts — POST:**
    - Zod schema: `z.object({ provider: z.enum(['anthropic','openai','deepseek']) })`
    - Call `withTenant()` for tenantId
    - Get provider via `getAiProvider(tenantId)` — if `!provider.isAvailable()` return 503 `apiError('FEATURE_DISABLED', 'Provider not configured', 503)`
    - Measure: `const start = Date.now()`
    - Call: `const result = await provider.complete('ping', { maxTokens: 5 })`
    - Calculate: `const latencyMs = Date.now() - start`
    - Return: `apiSuccess({ ok: true, provider: result.provider, latencyMs })`
    - On error: catch, return `apiError('INTERNAL_ERROR', 'Connection test failed: ' + error.message, 502)`
