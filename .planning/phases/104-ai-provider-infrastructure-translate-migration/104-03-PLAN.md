<objective>
Build the platform admin API routes for AI pool management, the monthly cron rollover route, and the tenant-facing `admin-ai-usage` widget. Platform admins manage tier quotas, view usage across tenants, override quotas, view capability costs, and check provider status. Tenant admins see a read-only usage bar with per-feature breakdown. Cron auto-settles each month's usage.

Purpose: The admin surface and automation layer for the platform AI pool. Without these routes, no one can see or manage AI usage. Without the cron, monthly rollover is manual. Without the widget, tenant admins have no visibility into their AI consumption.

Output: 6 platform admin API routes, 1 cron route, 1 tenant widget, widget registration, feature barrel.
</objective>
