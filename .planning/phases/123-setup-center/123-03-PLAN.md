# Plan 123-03: Setup Center Page Shell

## Goal

Create the `/setup` page shell — a permanent admin workspace that replaces the mandatory onboarding wizard. Build the main SetupCenter component with a progress bar and four-section layout. Integrate into navigation behind the `enable-setup-center` feature flag.

## Pre-flight

This phase executes inside `phase-123-setup-center` worktree. Verify:

## Tasks

### Task 1: Server component page route

<files>src/app/(tenant)/setup/page.tsx</files>
<action>

Create the `/setup` page as a server component:

- Reads tenant context from `withTenant()` middleware (already enforced)
- Queries Drizzle directly for initial `TenantSetup` data (NOT via fetch to own API — use `db.select().from(tenantSetup)...` pattern)

### Task 4: useSetupProgress hook

<files>src/features/setup/model/useSetupProgress.ts</files>
<action>

Create `useSetupProgress(tenantId)` hook:

- Fetches setup data via `GET /api/platform/setup?tenantId=<id>` on mount
- Returns `{ setup, isLoading, error, refreshProgress, updateMission, updateSetting }`
- `updateMission(missionKey, isCompleted)` calls PATCH API and updates local state
- `updateSetting(key, value)` calls PATCH API for settings
- Uses TanStack Query (`useQuery` + `useMutation`) for cache management

</action>
<verify>Hook returns correct shape, mutations update local state optimistically, errors surface to UI</verify>
<done>Data fetching hook with mutation support</done>
