Integrate the Setup Center into the existing dashboard experience. Show setup progress on the HomeLayer, update the post-signup redirect, and build the continuous Community Health view for post-launch tenants.

### Task 3: Update post-signup redirect

<files>src/features/auth/model/useSignupForm.ts</files>
<action>

Modify the signup success handler:

- Current: `router.push('/onboarding/${tenantId}')`
- New: Check `enable-setup-center` feature flag
  - If flag is ON: `router.push('/setup')`
  - If flag is OFF: `router.push('/onboarding/${tenantId}')` (existing behavior)

This preserves the existing flow for tenants where the feature flag is off, enabling gradual rollout.

</action>
<verify>With flag on: signup redirects to /setup. With flag off: signup redirects to /onboarding/[tenantId] (unchanged).</verify>
<done>Post-signup redirect behind feature flag</done>
