### Task 3: Recommendation engine (pure function)

<files>src/features/setup/model/recommendations.ts</files>
<action>

Create `getRecommendations(setup, tier)` — a **pure function** with no side effects:

```typescript
export function getRecommendations(
  setup: TenantSetup,
  tier: TierLevel
): SetupMission[]
```

Rules:
- If `completionPercent < 30` → recommend completing Launch missions
- If population count (from SetupSetting `populate.stats`) < 5 → recommend "Invite more residents"
- If module X is enabled but configuration mission incomplete → recommend "Configure X"
- Tier-aware: don't recommend premium/enterprise features to foundation tenants
- If `dWallet` is enabled but `DataRevenueStream` seed missing → recommend "Set up data revenue"
- If no surveys exist → recommend "Create your first survey"
- If no achievements enabled → recommend "Enable community achievements"

Each recommendation includes: `missionKey`, `title`, `description`, `estimatedTime` (from metadata), `benefits` (from metadata), `priority` (calculated).

The function must be **pure** — takes data in, returns recommendations out. No API calls, no database queries, no side effects. This makes it trivially testable.

</action>
<verify>

```bash
pnpm vitest run src/features/setup/model/__tests__/recommendations.test.ts
```

Passes with test cases covering all rule branches.

</verify>
<done>Pure function recommendation engine with full unit test coverage</done>
