This is a thin route file — a server component wrapper per Next.js 14 App Router convention. It imports the page module from @pages/disputes and wraps in Suspense.

Follow RESEARCH.md Pattern 4 exactly:

```typescript
import { DisputeDetailPage } from '@pages/disputes';
import { Suspense } from 'react';
import { LoadingSpinner } from '@shared/ui';

export default function DisputeDetailRoute({ params }: { params: { id: string } }) {
  return (
    <Suspense fallback={<LoadingSpinner />}>
      <DisputeDetailPage disputeId={params.id} />
    </Suspense>
  );
}
```

Notes:

- params.id is the URL segment — Next.js 14 provides it directly (not via a Promise)
- The file location src/app/(dashboard)/disputes/[id]/page.tsx creates the route /disputes/[id] behind the dashboard layout group, which means it inherits dashboard layout (auth protection, tenant context, space chrome)
- LoadingSpinner from @shared/ui is the project's standard Suspense fallback
- No 'use client' directive here — this is a server component
- Export default function (Next.js App Router convention)
- No generateMetadata or generateStaticParams needed for this phase (dynamic route, no static generation)
