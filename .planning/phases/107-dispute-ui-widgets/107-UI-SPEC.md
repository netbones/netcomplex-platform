## Spacing Scale

Declared values (multiples of 4, following Tailwind v3 defaults):

| Token | Value               | Usage                                                 |
| ----- | ------------------- | ----------------------------------------------------- |
| xs    | 4px (p-1, gap-1)    | Icon gaps, inline padding, tight badges               |
| sm    | 8px (p-2, gap-2)    | Compact element spacing, form field gaps              |
| md    | 16px (p-4, gap-4)   | Default element spacing, widget padding, card padding |
| lg    | 24px (p-6, gap-6)   | Section padding, wizard step separation, column gaps  |
| xl    | 32px (p-8, gap-8)   | Layout gaps, detail page column separation            |
| 2xl   | 48px (p-12, gap-12) | Major section breaks, header-to-content               |
| 3xl   | 64px (p-16, gap-16) | Page-level spacing                                    |

Exceptions: none

**Existing pattern alignment:** All 13 dispute entity components use Tailwind spacing classes (`px-2.5 py-0.5` for badges, `gap-4` for layout). Phase 107 components continue this pattern — no custom pixel values outside the 4-multiple scale.

**Touch targets:** Interactive elements (buttons, tab toggles, checkboxes) must have a minimum 44px clickable area on mobile (md:h-10 md:min-h-[44px] or h-11). Applied to:

- Wizard step indicators (numbered inline steps)
- Widget action buttons ("File a Dispute", "View", "Assign Moderator")
- Detail page mobile tab toggles
- Form checkboxes in SelfResolutionChecklist

## Typography

| Role    | Size | Weight | Line Height | Tailwind Class           | Usage                                                                                      |
| ------- | ---- | ------ | ----------- | ------------------------ | ------------------------------------------------------------------------------------------ |
| Micro   | 12px | 400    | 1.25        | `text-xs`                | Status badges, category badges, severity indicator, timestamps, form hints                 |
| Body    | 14px | 400    | 1.5         | `text-sm`                | Widget card text, form labels, filter tabs, list rows, mediation messages, checklist items |
| Heading | 18px | 600    | 1.3         | `text-lg font-semibold`  | Widget titles, wizard step headings, section headers on detail page, card titles           |
| Display | 24px | 600    | 1.2         | `text-2xl font-semibold` | Page title on `/disputes/[id]`, wizard modal title, empty state headings                   |

**Justification (2 weights only):**

- `400` (regular / `font-normal`) — body, labels, micro, helper text
- `600` (semibold / `font-semibold`) — headings, display, emphasized labels, CTA button text

**Existing pattern alignment:** DisputeStatusBadge uses `text-xs` (12px). MediationThread uses Tailwind defaults. No Heading or Display declarations existed in the dispute entity layer — these are established here.

**Form-specific:** Form input text uses 14px (Body). Validation error messages use 12px (Micro) in red-600.

### Accent Reserved For (exhaustive list)

The accent color `#4F46E5` (soralia-primary / indigo-600) is reserved for:

1. **Primary CTA buttons** — "File a Dispute" in my-disputes widget, "Submit Dispute" in form, "Send" in mediation thread

3. **Active tab indicators** — underline/background on active mobile tab, active filter tab in admin widget
4. **Completed wizard step checkmarks** — ✓ markers on finished steps
5. **Progress indicators** — form step indicators, loading spinners
6. **Links** — clickable text links within wizard tips and dispute detail page
7. **LoadingSpinner** — existing shared component already uses indigo

## Interaction Contracts

### Widget Lifecycle (my-disputes)

```
[List View] ──"File a Dispute" CTA──→ [Wizard Step 1..4] ──"Continue to Form"──→ [DisputeForm]
       ↑                                                                                │
       │                                                                                │ POST /api/disputes
       │                                                                                │
       └──────────────────── "Back to list" (any stage) ────────────────────────────────┘
                                                                                         │
                                                                                         ▼
                                                                              Navigate to /disputes/[id]
```

States: `list` → `wizard` → `form` → `redirect`
Cancellation: at any wizard/form step, "Back to list" returns to `list` state, discarding progress.
Form success: navigates away from widget entirely.

### Wizard State Machine

```
emotion → checklist → frivolity → tips → form
                        ↑ (skipped when AI disabled)
```

- Forward-only transitions (no back button per CONTEXT.md decision)
- AI step auto-skipped when `aiEnabled=false` (passed as prop)
- Stage 1 soft gate: non-blocking modal/dialog if "Very angry" or "Upset"
- Stage 2 tip: surface inline if <2 checkboxes checked

### Mobile Behavior

| Surface             | Desktop                  | Mobile                                                            |
| ------------------- | ------------------------ | ----------------------------------------------------------------- |
| Intake wizard       | Inline in widget         | Full-width takeover (bypasses widget grid)                        |
| Detail page         | 3-column layout          | Stacked single column with tab bar (Timeline / Thread / Evidence) |
| Detail page tabs    | Not applicable           | Bottom-sticky tab bar, Thread default                             |
| Detail page actions | Left column ActionsBar   | Sticky bottom bar (Actions + CoolingOff + CSOS)                   |
| Widget cancelling   | "Back to list" text link | Full-width "← Back to list" button                                |

### Responsive Breakpoints

Follow Tailwind defaults:

- `sm`: 640px — mobile widget takeover
- `md`: 768px — detail page 2→3 column transition
- `lg`: 1024px — full 3-column layout with proper widths

Detail page column widths (desktop):

- Left (Timeline + Actions): `md:col-span-1 md:w-64 lg:w-72`
- Center (Mediation): `md:col-span-2` (flex-grow)
- Right (Evidence + AI): `md:col-span-1 md:w-64 lg:w-72`
- Header: full-width above all three columns
