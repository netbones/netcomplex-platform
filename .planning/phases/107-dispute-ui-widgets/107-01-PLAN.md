Create src/shared/lib/useAutoSave.ts per RESEARCH.md Pattern 2 — localStorage Auto-Save:
- Import { useLocalStorage, useDebounceValue } from 'usehooks-ts' (project uses v3.1.1 — useDebounceValue is the v3 API, NOT useDebounce)
- Define UseAutoSaveOptions&lt;T&gt; interface: { key: string, data: T, delay?: number (default 2000), enabled?: boolean (default true) }
- Implement useAutoSave&lt;T&gt;({ key, data, delay = 2000, enabled = true }): 
  1. const [debouncedData] = useDebounceValue(data, delay) — debounce the input data
  2. const [savedData, setSavedData] = useLocalStorage&lt;T | null&gt;(key, null) — persist to localStorage
  3. useEffect that runs when debouncedData changes: if enabled, call setSavedData(debouncedData) and reset secondsSinceSave
  4. Track secondsSinceSave via setInterval (1s tick) that computes Math.floor((Date.now() - lastSavedAt) / 1000)
  5. Clean up interval on unmount
  6. Return { savedData, secondsSinceSave, clearSaved: () => setSavedData(null) }
- Wrap setSavedData in try/catch for QuotaExceededError — on catch, console.warn and set secondsSinceSave to null
- Mark the file with 'use client' directive (uses browser-only localStorage)
