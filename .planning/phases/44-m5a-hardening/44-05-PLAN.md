## Tasks

### Task 1: Delete schemas.ts from shared/api (znjo — schemas cluster, removes ~14 violations)

**Scope:** `src/shared/api/schemas.ts` + ~30 consumer files

`schemas.ts` re-exports schemas and types from 7 entity slices. This is a layer inversion — shared should not depend on entities. Fix:

1. Find all consumers of `schemas.ts` (via `@api/shared` barrel)
2. Redirect each consumer to import from the entity barrel directly:
   - `contentSchema` → `@entities/content`
   - `bookingSchema` → `@entities/booking`
   - `eventSchema` → `@entities/events`
   - etc.
3. Remove `schemas.ts` and its re-export from `@api/shared/index.ts`

**Validation:** `rg "schemas" src/shared/api/shared/index.ts` returns nothing. `pnpm fsd:check` reports 0 `shared → entities` forbidden imports for schemas.
