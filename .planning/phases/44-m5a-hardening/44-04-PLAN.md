## Context

Steiger reports **389 `no-public-api-sidestep` violations** for `@api/*` deep imports across 51+ files. This is the largest single FSD debt cluster in the codebase (BD qjpa).

The root cause: `tsconfig.json` only defines `@api/*` (wildcard), not `@api` (barrel). The barrel `src/shared/api/index.ts` already re-exports everything, but it's **unsafe to use** because it merges server-only and client-only modules:

| File | Runtime | Problem if barrel-merged |
|------|---------|--------------------------|
| `db.ts` | `import 'server-only'` | Crashes client bundles |
| `auth-client.ts` | `better-auth/react` (client) | Pulls React into server |
| `auth.ts` | `better-auth` (server) | Server-only APIs in client |
| `revalidation.ts` | `next/cache` (server) | Crashes client bundles |
| `gate.ts` / `feature-gate.ts` | server | Depends on `db`, `next/headers` |
| `schemas.ts` | isomorphic | Safe either way |
| `api-response.ts` | isomorphic | Safe either way |
| `dto/*` | isomorphic | Safe either way |
| `rate-limit.ts` | server | Depends on `db` |

**A single barrel `@api` is architecturally wrong.** The fix requires splitting `@api` into runtime-aware sub-barrels so consumers import from the correct context without deep-path sidesteps.

## Goal

Eliminate all 389 `@api/*` sidestep violations by introducing **3 sub-barrels** with `tsconfig` aliases, then migrating all consumers. After this plan, `import { db } from '@api/db'` becomes `import { db } from '@api/server'` — no deep import, no FSD violation.

## Architecture Decision

### Sub-barrel design

| Alias | Path | Runtime | Contents |
|-------|------|---------|----------|
| `@api/server` | `src/shared/api/server.ts` | Server only | `db`, `auth`, `revalidation`, `gate`, `feature-gate`, `rate-limit`, `audit-log`, `observability`, `supabase` (server client), `trpc/server`, `trpc/routers`, `email/*` |
| `@api/client` | `src/shared/api/client.ts` | Client only | `auth-client`, `turnstile` |
| `@api/shared` | `src/shared/api/shared.ts` | Isomorphic | `api-response`, `schemas`, `types`, `slug`, `storage`, `http-client`, `data-fetching`, `dto/*`, `auth-schemas`, `auth-utils` |

### tsconfig.json changes

```jsonc
// Before:
"@api/*": ["./src/shared/api/*"]

// After:
"@api": ["./src/shared/api"],           // barrel (kept for backward compat during migration)
"@api/server": ["./src/shared/api/server"],
"@api/client": ["./src/shared/api/client"],
"@api/shared": ["./src/shared/api/shared"],
"@api/*": ["./src/shared/api/*"]        // keep during migration, remove in cleanup task
```

### Steiger config

Add `@api/server`, `@api/client`, `@api/shared` to the `no-public-api-sidestep` allow list — these ARE the public APIs for the `@api` slice. Deep imports (`@api/db`, `@api/auth`, etc.) remain violations.

### Migration strategy

Each consumer file gets its deep import replaced with the correct sub-barrel:

```typescript
// Before (violation):
import { db } from '@api/db';
import { apiResponse } from '@api/api-response';
import { authClient } from '@api/auth-client';

// After (compliant):
import { db } from '@api/server';
import { apiResponse } from '@api/shared';
import { authClient } from '@api/client';
```

### Existing barrel (`@api/index.ts`)

Kept unchanged during migration for backward compat. Once all consumers are migrated (Task 5), the `@api/*` wildcard alias and the old barrel can be removed.

## Risk Assessment

| Risk | Mitigation |
|------|-----------|
| Sub-barrel pulls wrong runtime module | Task 1 validation: `pnpm build` catches "server-only in client" |
| Name collisions between sub-barrels | Sub-barrels use explicit `export { x } from './y'` — not `export *` — to avoid collisions |
| Circular dependency in sub-barrel | `auth-utils` is isomorphic but used by both `auth` (server) and `auth-client` (client). It goes in `@api/shared`. |
| Large batch migration introduces typo | Use codemod-style find-replace per sub-batch. Verify after each sub-batch. |
| `dto/*` deep imports | `@api/shared` re-exports from `./dto/index`. `@api/dto/maintenance` → `@api/shared`. |
