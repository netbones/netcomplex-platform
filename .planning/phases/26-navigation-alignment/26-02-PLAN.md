<files>src/shared/ui/MobileMenu.tsx, public/locales/en/common.json</files>
<action>
Rewrite `MobileMenu.tsx` to match the governance burger menu spec with 4 sections.

**Remove:** The local `NavItem` interface (lines 11-14), the flat navItems rendering, and the inline workspace/admin links.

**Import:**

```typescript
import { getBurgerSections, type NavItem } from '@/shared/lib/navigation-config';
import type { PlatformPageFlags } from '@entities/tenant/api/flags/platform-flags';
```

**Props update:**

```typescript
interface MobileMenuProps {
  isOpen: boolean;
  onClose: () => void;
  pageFlags: PlatformPageFlags | null;
  isAuthenticated: boolean;
  role: string | null;
}
```

**Render the 4 governance sections:**

```tsx
{isMounted && flags && (
  <div className="mt-4 p-4 bg-soralia-primary border-t-4 border-white">
    {/* Explore */}
    <div className="text-xs font-semibold text-white/70 uppercase tracking-wider mb-2 px-3">
      {t('nav.explore')}
    </div>
    {sections.explore.map(item => <Link .../>)}

    <div className="border-t border-white/20 my-2" />

    {/* Community */}
    <div className="text-xs font-semibold text-white/70 uppercase tracking-wider mb-2 px-3">
      {t('nav.community')}
    </div>
    {sections.community.map(item => <Link .../>)}

    {/* My Space (only if authenticated) */}
    {isAuthenticated && sections.workspace.length > 0 && (
      <>
        <div className="border-t border-white/20 my-2" />
        <div className="text-xs font-semibold text-white/70 uppercase tracking-wider mb-2 px-3">
          {t('nav.mySpace')}
        </div>
        {sections.workspace.map(item => <Link .../>)}
      </>
    )}

    {/* Administration (only if admin items exist) */}
    {isAuthenticated && sections.admin.length > 0 && (
      <>
        <div className="border-t border-white/20 my-2" />
        <div className="text-xs font-semibold text-white/70 uppercase tracking-wider mb-2 px-3">
          {t('nav.administration')}
        </div>
        {sections.admin.map(item => (
          <Link className="...text-gold-vein font-medium" .../>
        ))}
      </>
    )}

    {/* Auth actions */}
    <div className="border-t border-white/20 mt-4 pt-4">
      {isAuthenticated ? signout button : signin link}
    </div>
  </div>
)}
```

Where `sections = getBurgerSections(flags, isAuthenticated, role)`.

**Unauthenticated users:** See Explore + Community sections only. TeaserLink behavior for explore items that require auth (same as current Header TeaserLink — show toast "available to residents only").

**Authenticated users:** See all 4 sections.

Note: "events" already exists as `nav.events` in common.json.
