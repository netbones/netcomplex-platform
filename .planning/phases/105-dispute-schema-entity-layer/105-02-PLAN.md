    - `VALID_TRANSITIONS: Record<DisputeStatus, DisputeStatus[]>` — defines allowed forward transitions per ADVISORY-017 §6:

      - SUBMITTED → [UNDER_REVIEW, WITHDRAWN]
      - UNDER_REVIEW → [MEDIATION_OFFERED, FORMAL_RULING, WITHDRAWN]

      - MEDIATED_RESOLVED → [RESOLVED, WITHDRAWN]
      - FORMAL_RULING → [RESOLVED, ESCALATED_CSOS, WITHDRAWN]
      - RESOLVED → [] (terminal)
      - WITHDRAWN → [] (terminal)
      - ESCALATED_CSOS → [CSOS_CLOSED]
      - CSOS_CLOSED → [] (terminal)
    - `isTerminalStatus(status: DisputeStatus): boolean` — returns true for RESOLVED, WITHDRAWN, CSOS_CLOSED
    - `canTransition(from: DisputeStatus, to: DisputeStatus): boolean` — checks if `to` is in `VALID_TRANSITIONS[from]`
