Create 4 route files under `src/app/api/admin/platform/billing/`. Every route uses the Phase 46 platform admin pattern: `requirePlatformAdmin(request)` guard → try/catch → `apiSuccess()` / `apiInternalError()`. Each file sets `export const maxDuration = 8;`.

**Route 1: `plans/route.ts`**

- `GET` — List all billing plans across all tenants. Query: `db.select().from(billingPlans).orderBy(asc(billingPlans.sortOrder))`. Returns array of BillingPlan objects (all fields). Joined with tenant name via tenants table for display: `{ ...plan, tenantName: tenant.name }`.
- `PATCH` — Update a billing plan (name, description, monthlyPrice, annualPrice, modulesIncluded, pageLimits, seatLimits, aiQuota, isActive). Accept `{ planId, ...updates }` JSON body. Validate plan exists. Update only provided fields. Log with writeAuditLog.
- Imports: `import { billingPlans } from '@schema/billing-plan'; import { tenants } from '@schema/tenants'; import { eq, asc } from 'drizzle-orm';`

**Route 2: `subscriptions/route.ts`**

- `GET` — List all tenant subscriptions with optional query params: `?status=ACTIVE&tenantId=xxx&search=planName`. Join with tenants (name), billingPlans (name, tier). Return array of `{ subscription fields + tenantName + planName + planTier }`.
- `PATCH` — Admin override: cancel a subscription or change status. Accept `{ subscriptionId, status, reason? }`. Only allow setting CANCELLED or ACTIVE. Call tenant-billing cancelTenantSubscription or direct DB update for simpler status changes. Log with writeAuditLog.
- Imports: `import { tenantSubscriptions } from '@schema/tenant-subscription'; import { billingPlans } from '@schema/billing-plan';`

**Route 3: `invoices/route.ts`**

- `GET` — List all tenant invoices with optional `?tenantId=&subscriptionId=&status=`. Join with tenants (name). Order by createdAt desc. Return array of `{ invoice fields + tenantName + subscriptionPlanName }`. Support cursor pagination via `?cursor=id&limit=20`.
- No POST/PATCH — invoices are system-generated (immutable).
- Imports: `import { tenantInvoices } from '@schema/tenant-invoice';`

**Route 4: `payments/route.ts`**

- `GET` — List all tenant payments with optional `?tenantId=&status=&gateway=`. Join with tenants (name). Order by createdAt desc. Return array of `{ payment fields + tenantName }`. Support cursor pagination via `?cursor=id&limit=20`.
- No POST/PATCH — payments are system-generated or gateway-callback-driven.
- Imports: `import { tenantPayments } from '@schema/tenant-payment';`

**Guard pattern (same in all 4 routes):**

```typescript
export async function GET(request: NextRequest) {
  const guard = await requirePlatformAdmin(request);
  if (guard) return guard;
  try {
    // ... query logic
    return apiSuccess(data);
  } catch (error) {
    logError(
      { component: 'platform-billing-plans-api', operation: 'GET' },
      'Failed to list billing plans',
      error
    );
    return apiInternalError();
  }
}
```

  UI: Card container with max-h-[400px] overflow-y-auto scrollable table.
