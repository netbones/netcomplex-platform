# Plan 125-06: Document Upload Extension (storage.ts)

<objective>
Extend the existing S3-compatible storage module to support PDF/JPG/PNG document uploads alongside image uploads. Create a separate uploadDocument() function that bypasses the image-only type guard. Add Wave 0 upload test stubs for file type validation.
</objective>

<tasks>

<task id="125-06-01" type="execute">

**Add uploadDocument() function to src/shared/api/storage.ts**

<read_first>
- src/shared/api/storage.ts (existing uploadImage() — note ALLOWED_TYPES array, image-only guard on file.type.startsWith('image/'))
- .planning/phases/125-proxy-vote-module/125-CONTEXT.md §Step 3 (supported file types: PDF, JPG, PNG, max 10MB)
</read_first>

<action>
In src/shared/api/storage.ts:

1. Add ALLOWED_DOCUMENT_TYPES constant:
   - `['application/pdf', 'image/jpeg', 'image/png']`

2. Add MAX_DOCUMENT_SIZE constant:
   - `10 * 1024 * 1024` (10MB — CONTEXT.md requirement)

3. Create uploadDocument() function:
   - Signature: `uploadDocument(file: File, tenantId: string, subfolder?: string): Promise<{ url: string; key: string }>`
   - Validate file.type ∈ ALLOWED_DOCUMENT_TYPES (array via includes()) — reject with error message: "Invalid file type: {file.type}. Accepted: PDF, JPG, PNG"
   - Validate file.size ≤ MAX_DOCUMENT_SIZE — reject with error message: "File too large: {file.size} bytes. Maximum: 10MB"
   - Generate key: `tenants/{tenantId}/documents/{subfolder || 'proxy-forms'}/{crypto.randomUUID()}-{file.name}`
   - Upload to Supabase Storage bucket 'documents' (or reuse existing 'content-images' bucket)
   - Return { url, key } — URL uses NEXT_PUBLIC_SUPABASE_URL/public path (follow existing pattern)
   - Do NOT modify existing uploadImage() — create separate function; leave image-only guard on uploadImage() untouched

4. Export uploadDocument() from storage.ts barrel
</action>

<acceptance_criteria>
- uploadDocument() exists in src/shared/api/storage.ts
- uploadDocument(file.type='application/pdf', ...) passes validation
- uploadDocument(file.type='image/jpeg', ...) passes validation
- uploadDocument(file.type='image/png', ...) passes validation
- uploadDocument(file.type='text/html', ...) throws with "Invalid file type: text/html. Accepted: PDF, JPG, PNG"
- uploadDocument(file.size=15MB, ...) throws with "File too large: {size}. Maximum: 10MB"
- Existing uploadImage() unchanged — only image types still accepted
- Key format: `tenants/{tenantId}/documents/proxy-forms/{uuid}-{filename}`
- Return shape: `{ url: string; key: string }` matching existing uploadImage() return
- Supabase public URL generation follows existing pattern (not raw S3 URL)
</acceptance_criteria>
