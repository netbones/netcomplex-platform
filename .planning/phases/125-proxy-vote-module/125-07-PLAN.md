</read_first>

<action>
Create 4 components in src/features/proxy-vote/ui/:

1. SignatureCanvas.tsx:
   - Props: { onSignatureChange: (evidence: SignatureEvidence) => void; proxyOwnerName: string }
   - Mode toggle tabs: "Draw" | "Type" (text-sm, active tab = accent border-bottom-2, inactive = gray-400)
   - Draw mode: <SignaturePad /> from react-signature-canvas, with clear button (text-sm, gray-500), canvas border rounded-lg, min-h-[44px], bg-white
   - Type mode: text input (placeholder "Type your full name") + checkbox "I agree to act as proxy for {proxyOwnerName}" (label text per UI-SPEC copywriting)
   - Submit button: "Sign & Submit" (soralia-primary bg, 44px min touch target, disabled until signature present)
   - On submit: call onSignatureChange with INTERNAL SignatureEvidence (provider='INTERNAL', mode, signatureDataUrl or typedName, timestamp)
   - Validate: canvas non-empty (draw mode) OR typedName non-empty + checkbox checked (type mode)

2. ProxyQRCode.tsx:
   - Props: { referenceCode: string; size?: number }
   - Default size: 44×44px min
   - Render: <QRCodeSVG /> from qrcode.react, value=referenceCode, size=prop, bgColor='#FFFFFF', fgColor='#000000'
   - Container: bg-soralia-primary/5 rounded-lg border border-soralia-primary/20, p-3 (12px)
   - Label "QR Reference" (text-sm, gray-500) above QR area
   - Copy button: clipboard icon (lucide Copy) + "Copy" text label (text-xs, gray-500, inline-flex gap-1)
   - Clipboard: navigator.clipboard.writeText(referenceCode) → toast "Copied: {referenceCode}"

3. ProxySearchBox.tsx:
   - Props: { onSelect: (resident: ResidentResult | null) => void; onNonResident: (data: NonResidentData | null) => void }
   - ResidentResult: { userId: string; name: string; address: string }
   - NonResidentData: { name: string; email: string; phone: string }
   - Debounced search input (300ms useRef timer): "Who will represent you?" placeholder
   - Dropdown results: name (600 weight) + address (400 weight, gray-500), each result 44px min tap target
   - Selected state: highlight bg-soralia-primary/5 border border-soralia-primary/20 + green checkmark
   - "My proxy is not a resident" toggle below search — when active, expands: Name input, Email input, Phone input
   - Validation: either resident selected OR non-resident fields filled before allowing Next step

4. MeetingAttendancePrompt.tsx:
   - Props: { meetingTitle: string; meetingDate: string; onChoice: (attending: boolean) => void }
   - Title: meetingTitle (text-lg font-semibold) — focal point per UI-SPEC
   - Date: meetingDate (text-sm, gray-500)
   - Radio-style choice: "I will attend" (with green10B981 tint) | "I cannot attend" (with amber accent)
   - Selection required to continue
   - "I cannot attend" starts proxy flow (Step 1 complete → Step 2 appears)
   - "I will attend" registers attendance and exits wizard
</action>
