All 5 routes follow the exact same pattern as RESEARCH.md Pattern 1 (API Route — following resources pattern). Each file:

- Imports: getSessionAndRole, withTenant, withErrorHandler, db, relevant Drizzle tables, apiSuccess/apiError/apiUnauthorized/apiForbidden from @api/server
- Imports: eq, and, desc, sql from drizzle-orm
- Uses: `export const maxDuration = 8`
- Uses: `export const GET/POST = withErrorHandler(async (request, context?) => { ... })`
- Uses: `const sessionData = await getSessionAndRole(request)` → return apiUnauthorized() if null
- Uses: `const { tenantId } = await withTenant()`
- Uses: wallet fetched via getOrCreateWallet(userId, tenantId)
- Uses: apiSuccess(data) for success, apiError(code, msg, status) for errors
- Uses: `import { createComponentLogger } from '@/shared/lib'` for logging

ROUTE BY ROUTE instructions:

1. GET / (src/app/api/v1/tenant/dwallet/route.ts):
   - Get wallet via getOrCreateWallet(sessionData.userId, tenantId)
   - Fetch 8 active streams from dataRevenueStreams (tenantId filter + isActive=true)
   - Fetch current consent state per stream: for each active stream, get latest DataConsent row by (walletId, streamKey) using orderBy desc(createdAt) limit 1
   - Fetch 5 most recent transactions via orderBy desc(walletTransactions.createdAt) limit 5
   - Return DWalletSummary shape: { balance, lifetimeEarned, lifetimePaid, currency, status, consents: [...ConsentState], recentTransactions: [...TransactionItem] }

2. GET /transactions (src/app/api/v1/tenant/dwallet/transactions/route.ts):
   - Parse query params: page (default 1), limit (default 20), type (optional TransactionType filter), startDate/endDate (optional ISO strings)
   - Query walletTransactions filtered by walletId + tenantId, with optional type and date range filters
   - Order by desc(createdAt)
   - Paginate with limit/offset
   - Return paginated transaction list with total count

3. GET /consents (src/app/api/v1/tenant/dwallet/consents/route.ts):
   - Get wallet via getOrCreateWallet
   - Fetch all active streams from dataRevenueStreams
   - For each stream, get latest DataConsent row orderBy desc(createdAt) limit 1
   - Map to ConsentState[] (stream not in consents = granted: false as default)
   - Return array of { streamKey, label, description, granted, grantedAt, revokedAt }

4. POST /consents/:streamKey (src/app/api/v1/tenant/dwallet/consents/[streamKey]/route.ts) — CRITICAL ROUTE:
   - Parse body with consentSchema { granted: boolean }
   - Get wallet via getOrCreateWallet
   - Get streamKey from context.params
   - Validate stream exists and is active in dataRevenueStreams (404 if not)
   - INSERT new DataConsent row (never UPDATE — append-only per Constraint 2). Fields: id: crypto.randomUUID(), tenantId, walletId, userId, streamKey, granted, ipAddress: request.headers.get('x-forwarded-for'), userAgent: request.headers.get('user-agent'), grantedAt: body.granted ? now() : null, revokedAt: body.granted ? null : now(), createdAt: now()
   - Pino audit log: logger.info({ event: 'consent_change', userId: sessionData.userId, streamKey, granted: body.granted, tenantId, ip: request.headers.get('x-forwarded-for') })
   - Return apiSuccess({ streamKey, granted: body.granted })

5. GET /streams (src/app/api/v1/tenant/dwallet/streams/route.ts):
   - Query all active streams from dataRevenueStreams where tenantId + isActive=true
   - Return array of StreamConfig objects

EVERY ROUTE MUST: include tenantId in every Drizzle WHERE clause. Use string-based amounts (DECIMAL columns return strings from Drizzle). Never use Prisma client — Drizzle only.
