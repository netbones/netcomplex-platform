| admin→DB   | Admin API routes must not return individual PII (balances, consent choices)         |

## STRIDE Threat Register

| Threat ID | Category               | Component                | Disposition | Mitigation Plan                                                                                            |
| --------- | ---------------------- | ------------------------ | ----------- | ---------------------------------------------------------------------------------------------------------- |
| T-47-01   | Tampering              | WalletTransaction rows   | mitigate    | Immutable append-only design — no UPDATE/DELETE queries; corrections use ADJUSTMENT rows                   |
| T-47-02   | Information Disclosure | Admin routes             | mitigate    | Admin queries return aggregate counts/totals only; never individual balances or consent choices            |
| T-47-03   | Elevation of Privilege | Cross-tenant data access | mitigate    | Every query filters by tenantId; @@index on tenantId on all models                                         |
| T-47-04   | Repudiation            | Consent changes          | mitigate    | Pino audit log on every consent change with userId, streamKey, granted, tenantId, ip                       |
