1. GET /admin/dwallet/stats (src/app/api/admin/dwallet/stats/route.ts):
   - Auth + tenant isolation (standard pattern)
   - Return AdminStats shape — AGGREGATE ONLY (Constraint 5):
     a. optedInResidents: count of wallets where status='ACTIVE' AND at least one DataConsent row exists with granted=true (COUNT DISTINCT walletId)
     b. totalRewardsMonth: SUM(walletTransactions.amount) where type='CREDIT' AND createdAt >= start of current month
     c. pendingPayouts: COUNT(payoutRequests) where status='PENDING'
     d. totalOptedInAllStreams: total count of (walletId, streamKey) pairs where granted=true across all active streams
   - NEVER return: individual wallet balances, individual consent choices, individual transaction details
   - Use SQL aggregation: db.select({ count: sql`count(distinct ${dataConsents.walletId})` }).from(dataConsents).where(and(eq(dataConsents.tenantId, tenantId), eq(dataConsents.granted, true)))

2. GET + POST /admin/dwallet/batches (src/app/api/admin/dwallet/batches/route.ts):
   GET: List all DataShareBatch records for tenant, ordered by createdAt desc. Return BatchRecord[].
   POST: Create and run distribution batch — FOLLOW Pattern 4 from RESEARCH.md EXACTLY:
   a. Parse body with batchSchema { streamKey, periodStart, periodEnd, totalRevenue }
   b. Auth guard: if (!hasPermission(sessionData.role, 'admin')) return apiForbidden()
   c. Read stream config: db.select().from(dataRevenueStreams).where(and(eq(tenantId), eq(key, streamKey))). Verify stream exists and isActive=true
   d. Compute residentPool = totalRevenue \* stream.residentSharePct / 100 (use string-based Decimal math — convert to number, compute, keep as string)
   e. Get opted-in wallets: query DataConsent where tenantId matches, streamKey matches, granted=true. Get the LATEST consent per wallet (subquery with MAX(createdAt) grouped by walletId)
   f. perResidentAmount = residentPool / optedInWallets.length
   g. batchId = crypto.randomUUID()
   h. ATOMIC TRANSACTION (Drizzle .transaction()): - For each opted-in wallet, read current balance, insert WalletTransaction CREDIT with balanceBefore/balanceAfter, update wallet.balance += perResidentAmount and lifetimeEarned += perResidentAmount - DO NOT use .for('update') for row locking in Phase 1 (Drizzle proxy pattern may not support it reliably — rely on transaction isolation) - Insert DataShareBatch record with status='COMPLETED'
   i. If any step fails, CATCH the error: insert DataShareBatch with status='FAILED' and notes=error.message. Return apiError('INTERNAL_ERROR', 'Batch distribution failed — no credits applied', 500)
   j. On success: call revalidateDashboard(), return apiSuccess({ batchId, participantCount: optedInWallets.length, perResidentAmount })

DO NOT: apply partial credits on failure (the transaction ensures all-or-nothing). Do not expose individual wallet data in the response.
</action>

   - Auth guard: admin only
   - Parse body with payoutStatusSchema { status: 'COMPLETED'|'REJECTED', notes? }
   - Query payoutRequest by id with tenantId filter — 404 if not found
   - If status='COMPLETED':
     a. Get wallet (by payoutRequest.walletId with tenantId filter)
     b. Compute newBalance = balance - payoutRequest.amount (string-based Decimal math)
     c. INSERT WalletTransaction DEBIT: type='DEBIT', amount=(-1 \* payoutRequest.amount), balanceBefore=wallet.balance, balanceAfter=newBalance, description=`Payout disbursement (ref: ${payoutRequest.id})`, sourceType='RESIDENT_DATA_SHARE', referenceId=payoutRequest.id, referenceType='payout'
     d. UPDATE wallet: balance=newBalance, lifetimePaid += payoutRequest.amount
     e. UPDATE payoutRequest: status='COMPLETED', processedAt=now(), processedBy=sessionData.userId, notes=body.notes
   - If status='REJECTED':
     a. UPDATE payoutRequest: status='REJECTED', processedAt=now(), processedBy=sessionData.userId, notes=body.notes
     b. No balance change — resident keeps their funds
   - Return apiSuccess(updatedPayout)
   - Use Drizzle transaction for the COMPLETED flow (wallet update + txn insert + payout update must be atomic)
