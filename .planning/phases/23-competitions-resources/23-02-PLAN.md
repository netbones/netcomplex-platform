  <name>Task 1: Add Resource model, ResourceCategory enum, and ResourceVisibility enum to Prisma schema</name>
  <files>prisma/schema.prisma, src/db/schema/index.ts</files>
  <action>
    Add to prisma/schema.prisma following the DISCUSSION.md v3 specification:

    enum ResourceCategory {
      ARCHITECTURAL
      ENGINEERING
      GOVERNANCE
      BOARD_REPORT
      DIY
      FINANCIAL
      LEGAL
      OTHER
    }

    enum ResourceVisibility {
      ALL_RESIDENTS
      OWNERS_ONLY
      BOARD_ONLY
      COMMITTEE_ONLY
    }

    model Resource {
      id           String             @id @default(cuid())
      tenantId     String
      title        String
      description  String?
      category     ResourceCategory
      fileUrl      String?
      fileType     String?
      fileSize     Int?
      externalUrl  String?
      bodyContent  Json?
      version      String?
      visibility   ResourceVisibility @default(ALL_RESIDENTS)
      authorId     String?
      publishedAt  DateTime?
      createdAt    DateTime           @default(now())
      updatedAt    DateTime           @updatedAt
      user         user?              @relation(fields: [authorId], references: [id])

      @@index([tenantId])
      @@index([category])
      @@index([visibility])
    }

    Run `npx prisma generate` to regenerate Drizzle schema.
    Run `npx prisma db push` to apply migration.

    Do NOT remove RESOURCE from ContentCategory enum yet — that happens in Plan 03 after migration.

  </action>

  <name>Task 2: Create Resource API routes with visibility enforcement based on user role</name>
  <files>src/app/api/resources/route.ts, src/app/api/resources/[id]/route.ts</files>
  <action>
    Create two API route files following the events pattern but with visibility enforcement:

    src/app/api/resources/route.ts:
    - GET: List resources for the tenant. Apply visibility filtering based on user role:
      - ADMIN/MANAGER/BOARD: see ALL_RESIDENTS, OWNERS_ONLY, BOARD_ONLY, COMMITTEE_ONLY
      - COMMITTEE: see ALL_RESIDENTS, OWNERS_ONLY, COMMITTEE_ONLY
      - RESIDENT (owner): see ALL_RESIDENTS, OWNERS_ONLY (check if user owns a property)
      - RESIDENT (non-owner): see ALL_RESIDENTS only
      - Unauthenticated: see ALL_RESIDENTS only (for public resources page)
      Support query params: category (filter by category), visibility (admin-only filter).
      Use withTenant() for tenant scoping. Order by createdAt descending.
    - POST: Create a new resource. Requires ADMIN/MANAGER role via hasPermission(). Accept JSON body with title, description, category, fileUrl, fileType, fileSize, externalUrl, bodyContent, version, visibility, publishedAt. Set tenantId from withTenant(), authorId from session. Return 201.

    src/app/api/resources/[id]/route.ts:
    - GET: Read single resource by ID. Apply same visibility filtering as GET list.
    - PATCH: Update resource. Requires ADMIN/MANAGER role. Accept partial JSON body.
    - DELETE: Delete resource. Requires ADMIN role.

    Use Drizzle ORM (import from @api/db).
    Add revalidateContent() after POST/PATCH/DELETE.
    For visibility enforcement, create a helper function that builds the Drizzle WHERE clause based on role.

  </action>
