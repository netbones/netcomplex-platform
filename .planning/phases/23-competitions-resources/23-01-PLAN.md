<task type="auto">
  <name>Task 2: Create Competition API routes (GET, POST, PATCH, DELETE) with tenant scoping</name>
  <files>src/app/api/competitions/route.ts, src/app/api/competitions/[id]/route.ts</files>
  <action>
    Create two API route files following the existing events pattern (src/app/api/events/route.ts):

    src/app/api/competitions/route.ts:
    - GET: List all competitions for the tenant. Support query params: status (filter by status), upcoming (filter to startDate <= now AND endDate >= now). Use withTenant() for tenant scoping. Order by startDate descending.
    - POST: Create a new competition. Requires ADMIN/MANAGER role check via hasPermission(). Accept JSON body with title, description, rules, prizeInfo, startDate, endDate, image. Set status=DRAFT by default. Set tenantId from withTenant(). Return 201 with created competition.

    src/app/api/competitions/[id]/route.ts:
    - GET: Read single competition by ID. Verify tenantId match via withTenant().
    - PATCH: Update competition. Requires ADMIN/MANAGER role. Accept partial JSON body. Return updated competition.
    - DELETE: Delete competition. Requires ADMIN role. Return 200 with success message.

    Use the same auth pattern as events: getSessionAndRole() helper, withTenant() for tenant isolation, hasPermission() for role checks.
    Use Drizzle ORM (not Prisma client) for queries — import from @api/db.
    Add revalidateContent() call after POST/PATCH/DELETE mutations.

  </action>
  <verify>
    <automated>npm run typecheck</automated>
    <manual>curl -X GET /api/competitions returns 401 without auth, 200 with auth; curl -X POST /api/competitions with valid body returns 201</manual>

  </verify>
