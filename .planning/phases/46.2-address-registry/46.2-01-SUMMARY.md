## Decisions Made

- Used `@@unique([tenantId, address])` instead of `@unique` on address alone — enables cross-tenant address reuse
- Profile uses `aliasAddressId` (not `addressId`) per D-06 CONTEXT.md decision
- Migration FK defaults: ON DELETE SET NULL for seat tables, ON DELETE CASCADE for Handle/AddressEndpoint
- Used `prisma migrate deploy` instead of `prisma migrate dev` to bypass shadow database issue with pre-existing ALTER TYPE migration
- Address model uses `@default(cuid())` for id generation, consistent with Handle and AddressEndpoint
- Backfill uses `ON CONFLICT (tenantId, address) DO NOTHING` for safe re-runs; collision detection gate runs pre-flight
