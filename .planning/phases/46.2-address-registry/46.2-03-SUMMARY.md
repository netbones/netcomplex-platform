## Decisions Made

- AddressService.reserve() always wrapped in db.transaction() to prevent orphaned Address rows (adheres to ADVISORY-020 R-020-03)
- AddressService.generate() used in all route files for dynamic tenant domain resolution instead of hardcoded `soralia.org`
- Legacy platformAddress columns kept as denormalized cache — Phase 1 writes go through AddressService, reads still use legacy columns
- tRPC premium route throws TRPCError (CONFLICT, BAD_REQUEST) instead of apiConflict/apiError to match tRPC error convention
- System address seeding uses raw INSERT with ON CONFLICT DO NOTHING for idempotency (not AddressService, since seed file has its own db connection)

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed AddressService.generate() parameter mismatch in premium/portfolio route**

- **Found during:** Task 1
- **Issue:** Plan specified `AddressService.generate('PREMIUM', tenantId, { name: user.name || user.email })` but the PREMIUM kind in generate() uses `options.custom`, not `options.name`
- **Fix:** Pass the name as `options.custom` instead of `options.name` in both premium/portfolio/route.ts and premium.ts tRPC route
- **Files modified:** src/app/api/premium/portfolio/route.ts, src/server/routers/marketplace/premium.ts
- **Verification:** TypeScript compiles clean, tests pass
- **Committed in:** aa8c73af, f3a8f8b9 (Task 1 and Task 3 commits)

**2. [Rule 3 - Blocking] Test mock infrastructure needed updates for transaction pattern**

- **Found during:** Task 1
- **Issue:** Existing seat tests mocked `db.insert`/`db.select`/`db.delete` directly but the new code uses `db.transaction()`, `tx.update()`, and `AddressService.reserve()`. Tests failed with "Cannot read properties of undefined (reading 'where')" because `db.transaction()`, `db.update()`, `AddressService`, and `AddressConflictError` were not mocked
- **Fix:** Added `transaction` mock (calls callback with dbMock as tx), `update` mock (returns chainable .set().where()), `execute` mock, and `AddressService`/`AddressConflictError`/`AddressValidationError` class mocks to the test's `vi.mock('@api/server')`. Added `mockAddressReserve` vi.fn for controllable conflict simulation. Replaced `vi.restoreAllMocks()`/`vi.clearAllMocks()` with `vi.resetAllMocks()` in beforeEach/afterEach to properly clear mock state between tests. Updated the "returns 409 if platform address already allocated" test to use AddressService conflict instead of per-table db select
- **Files modified:** src/app/api/seats/**tests**/seats.test.ts
- **Verification:** All 17 tests pass
- **Committed in:** aa8c73af (Task 1 commit)
