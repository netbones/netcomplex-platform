### BLOCKER #1: must_haves.truths contradicts implementation (Plan 02)

**Plan 02, line 20 (must_haves.truths):**

> `AddressService.reserve() creates an Address record with RESERVED status and validates reserved names`

**Plan 02, line 112 (behavior):**

> `reserve('john@soralia.org', tenantId, 'SOLO') returns AddressRecord with status=ACTIVE`

**Plan 02, line 142 (action):**

> `Insert with crypto.randomUUID(), status=ACTIVE (not RESERVED per D-04 — ACTIVE is the initial state)`

The truth claims `RESERVED`, the implementation delivers `ACTIVE`. The action's rationale ("ACTIVE is the initial state") is consistent with CONTEXT.md's lifecycle: ACTIVE → COOLING_OFF → ARCHIVED → DELETED. RESERVED is a valid enum value but is not the initial state for newly reserved addresses.

**Fix:** Change line 20 to: `'AddressService.reserve() creates an Address record with ACTIVE status and validates reserved names'`
