**Step 5: Back-update FK columns** — AFTER backfill, run `UPDATE "StandardSeat" s SET "addressId" = a."id" FROM "Address" a WHERE a."ownerId" = s."id" AND a."ownerType" = 'STANDARD_SEAT'` for each of the 6 tables.

**Step 6: Create indexes** — `Address_tenantId_idx`, `Address_ownerType_ownerId_idx`, `Address_status_idx`, `Handle_addressId_idx`, `AddressEndpoint_addressId_idx`.

**Step 7: Pre-migration safety checks** — Include the duplicate detection query from RESEARCH.md Risk 1 as a comment block at the top of the migration. If duplicates exist between source tables sharing the same address string, `ON CONFLICT DO NOTHING` will silently keep the first insert — the comment documents this as a known behavior.

After sql is written, run `npx prisma migrate dev --name add_address_registry` to apply. Then run `npx prisma generate` to regenerate Drizzle schema files.
