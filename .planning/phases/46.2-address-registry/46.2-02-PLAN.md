Build the AddressService and HandleService classes — the programmatic API for all address registry operations. Create `src/shared/api/address-service.ts`. Use `import 'server-only'` at the top. Follow the class-based pattern from `PayPalService`/`PaystackService`:

```typescript
import 'server-only';
import { eq, and } from 'drizzle-orm';
import type { NodePgDatabase } from 'drizzle-orm/node-postgres';
import { db, addresses } from './db';
import type { DbSchema } from './db';
// ... additional imports for handles, enums
```

**Class structure:**

- `constructor(tx?: NodePgDatabase<DbSchema>)` — stores `this.db = tx ?? db` for transaction injection
- Private helpers: `validateAddressFormat(address)`, `isReservedName(localPart)`, `parseAddress(address)` returns { localPart, domain }
- Public methods (each returns typed result, never raw query results):

**reserve(address, tenantId, kind, options?):** Validate format and reserved names. Check uniqueness via `this.db.select().from(addresses).where(and(eq(addresses.address, address), eq(addresses.tenantId, tenantId))).limit(1)`. If exists, throw `AddressConflictError`. Insert with `crypto.randomUUID()`, status=ACTIVE (not RESERVED per D-04 — ACTIVE is the initial state), set localPart/domain from parseAddress, createdAt=now().

**release(addressId):** Update status to DELETED, set releasedAt=now().

**resolve(addressOrHandle, tenantId):** Try direct address match first, then try handle resolution via HandleService. Return AddressRecord or null.

**move(addressId, newAddress, tenantId):** Validate newAddress format and reserved names. Check uniqueness of newAddress. Update address, localPart, domain fields atomically.

**forward(addressId, strategy):** Update forwardStrategy field (DIRECT or HOUSEHOLD).

**archive(addressId):** Set status=ARCHIVED, archivedUntil=now() + 90 days.

**lookup(ownerType, ownerId, tenantId):** Query by `and(eq(addresses.ownerType, ownerType), eq(addresses.ownerId, ownerId), eq(addresses.tenantId, tenantId))`.

**validate(address):** Check format (must contain @, must have valid localPart and domain). Throw `AddressValidationError` on failure.

**generate(kind, tenantId, options):** Generate address string from kind and options. For STANDARD: `unit{options.unitNumber}@soralia.org`. For ALIAS: `{options.name}.unit{options.unitNumber}@soralia.org`. For SOLO: `{options.name}@soralia.org`. For PREMIUM: `{options.custom}@soralia.org`. For PROVIDER: `{slugifiedCompanyName}@soralia.org`.

**Error classes:** Define and export `AddressConflictError extends Error`, `AddressValidationError extends Error`, `AddressNotFoundError extends Error` — typed domain errors that callers (API routes, tRPC procedures) can catch to produce appropriate HTTP responses.

**Reserved names enforcement (per CONTEXT.md):** The private `isReservedName()` checks against: admin, support, system, billing, help, maintenance, security, office, community, events. Non-admin callers cannot reserve these addresses — throw AddressConflictError with specific message.

Create `src/shared/api/handle-service.ts`. Same class-based pattern as AddressService:

**Class structure:**

- `constructor(tx?: NodePgDatabase<DbSchema>)` — transaction injection
- Private helpers: `isReservedHandle(handle)` — same reserved names list as AddressService
- Public methods:

**search(prefix, tenantId, limit?=20):** Query handles where `handle ILIKE prefix%` within tenantId. Use Drizzle `ilike` or `like` with `startsWith`. Return array of { handle, addressId, status }.

**register(handle, addressId, tenantId):** Validate handle format (alphanumeric + dots, no @). Check reserved names. Verify addressId exists in Address table. Insert with `crypto.randomUUID()`, status=ACTIVE. Catch DB unique constraint violation → throw HandleConflictError.

**release(handleId):** Update status to RELEASED.

**resolve(handle, tenantId):** Query `eq(handles.handle, handle)` AND `eq(handles.tenantId, tenantId)` AND status=ACTIVE. If found, join to Address table and return full address record. If not found, return null.

**Error classes:** Define and export `HandleConflictError extends Error`, `HandleNotFoundError extends Error`.

The HandleService should NOT import AddressService directly to avoid circular deps. Instead, it queries the handles table directly. The `resolve()` method joins to the addresses table via Drizzle to return the full address.
