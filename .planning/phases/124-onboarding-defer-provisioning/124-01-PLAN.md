<objective>
Make `tenantId` nullable at every layer — database, ORM, auth framework, and RLS context — so a verified user can exist in the system without belonging to a tenant. This is the Phase 0 prerequisite from ADVISORY-031 §10; it unblocks all other plans (124-02 through 124-06).

Purpose: Dismantle the three-layer null-prevention enforcement (DB NOT NULL, Better Auth `required:true`+`defaultValue`, and the `user.create.before` hook's unconditional fallback) so `tenantId: null` becomes a durable, first-class state.

Output: Applied Prisma migration, regenerated Drizzle schema, relaxed Better Auth config, null-safe RLS context, and a bounded consumer audit confirming compile-clean under `string | null`.
</objective>
