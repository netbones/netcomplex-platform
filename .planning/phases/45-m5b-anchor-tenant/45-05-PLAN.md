**Step A — Add dirty tracking state:**
At the top of the ContentForm function, after existing hooks (line 88-102), add:

```typescript
// Track whether the current locale's content has been modified
const [localeDirtyState, setLocaleDirtyState] = useState<Record<string, boolean>>({});
const [pendingLocaleChange, setPendingLocaleChange] = useState<SupportedLanguage | null>(null);
```

**Step B — Mark locale as dirty on content change:**
When the title or content changes for the active locale, mark it dirty. The simplest approach: use a `useEffect` on `formValues.title` and `formValues.content`:

```typescript
// Mark current locale as dirty when content changes
useEffect(() => {
  const hasTitle = !!formValues.title?.[activeLocale]?.trim();
  const hasContent = !!formValues.content?.[activeLocale]?.trim();
  if (hasTitle || hasContent) {
    setLocaleDirtyState(prev => ({ ...prev, [activeLocale]: true }));
  }
}, [formValues.title, formValues.content, activeLocale]);
```

Clear dirty state on successful save:

- In the `onSubmit` handler's success path (after line 160), add:

```typescript
setLocaleDirtyState(prev => ({ ...prev, [activeLocale]: false }));
```

**Step C — Modify handleLocaleChange to check dirty state:**
Replace the existing `handleLocaleChange` (line 106-108) with:

```typescript
const handleLocaleChange = useCallback(
  (locale: SupportedLanguage) => {
    if (locale === activeLocale) return;
    if (localeDirtyState[activeLocale]) {
      // User has unsaved changes — show confirmation
      setPendingLocaleChange(locale);
    } else {
      switchLocale(locale);
    }
  },
  [activeLocale, localeDirtyState]
);
```

Add the `switchLocale` helper:

```typescript
const switchLocale = useCallback((locale: SupportedLanguage) => {
```

**Step F — Prevent dirty state on initial load:**
When `initialData` is provided (editing existing content), do NOT mark locales as dirty — only mark dirty when the user actually modifies content. The `useEffect` in Step B will handle this correctly because it runs after the first render. However, ensure the initial `useEffect` doesn't fire on mount by checking that `formValues` differs from `initialData`. Simplest approach: use a `useRef` to track initial render skip:

```typescript
const isInitialRender = useRef(true);
useEffect(() => {
  if (isInitialRender.current) {
    isInitialRender.current = false;
    return;
  }
  const hasTitle = !!formValues.title?.[activeLocale]?.trim();
  const hasContent = !!formValues.content?.[activeLocale]?.trim();
  if (hasTitle || hasContent) {
    setLocaleDirtyState(prev => ({ ...prev, [activeLocale]: true }));
  }
}, [formValues.title, formValues.content, activeLocale]);
```
