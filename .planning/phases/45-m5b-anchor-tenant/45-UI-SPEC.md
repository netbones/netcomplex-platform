| Token | Value | Usage                     |

| md    | 16px  | Default element spacing   |
| lg    | 24px  | Section padding           |

## Typography

| Role    | Size            | Weight | Line Height |
| ------- | --------------- | ------ | ----------- |
| Body    | 14px (text-sm)  | 400    | 1.6         |
| Label   | 12px (text-xs)  | 400    | 1.2         |
| Heading | 24px (text-2xl) | 700    | 1.2         |
| Display | 30px (text-3xl) | 700    | 1.1         |

Body and Label share weight 400; they are distinguished by size (14px vs 12px) and line-height (1.6 vs 1.2).

## Visual Hierarchy

### Primary Screen — Merits Admin Page (`/admin/merits`)

Focal point priority, 1 → 2 → 3 ordering:

| Priority      | Element                                         | Rationale                                                                                                         |
| ------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 1 (Primary)   | Behavior records data table                     | Core data display; occupies the center of the viewport; users spend most time scanning and filtering records here |
| 2 (Secondary) | "Record Entry" CTA in page header               | Primary action — the dominant user intent upon landing; visually anchored top-right with accent color (#4F46E5)   |
| 3 (Tertiary)  | Standing badge summary row (above table header) | Quick-glance resident standings; compact horizontal strip; supports table context                                 |

### Primary Screen — OTP Verification Page

Focal point priority, 1 → 2 → 3 ordering:

| Priority      | Element                    | Rationale                                                                                     |
| ------------- | -------------------------- | --------------------------------------------------------------------------------------------- |
| 1 (Primary)   | OTP input field (6-digit)  | The sole user task; input receives auto-focus; largest text on the card                       |
| 2 (Secondary) | "Send Code" / "Verify" CTA | Action triggers; directly below input; uses accent color                                      |
| 3 (Tertiary)  | 5-minute expiry countdown  | Time-pressure indicator; subtle placement below CTA; low visual weight unless ≤ 60s remaining |

## Color

| Role            | Value                            | Usage                                                                |
| --------------- | -------------------------------- | -------------------------------------------------------------------- |
| Dominant (60%)  | #F3F4F6 (soralia-light)          | Page background, empty surfaces                                      |
| Secondary (30%) | #FFFFFF / #1F2937 (soralia-dark) | Cards, table rows, sidebar, navigation                               |
| Accent (10%)    | #4F46E5 (soralia-primary)        | Primary CTAs, form focus rings, active nav states, badge backgrounds |
| Destructive     | #DC2626 (red-600)                | Delete buttons, destructive confirmation dialogs                     |

Accent reserved for: primary button backgrounds, form input focus rings, active navigation item indicators, standing badge header backgrounds (via CARD_HEADER_COLORS). Never use accent for body text or non-interactive borders.

### Standing Tier Badge Colors (Phase-specific)

| Tier      | Threshold   | Icon                     | Color Classes                   |
| --------- | ----------- | ------------------------ | ------------------------------- |
| Gold      | points ≥ 50 | `ShieldCheck` (lucide)   | `bg-amber-100 text-amber-800`   |
| Silver    | points ≥ 20 | `Shield` (lucide)        | `bg-gray-200 text-gray-700`     |
| Bronze    | points ≥ 0  | `Shield` (lucide)        | `bg-orange-100 text-orange-800` |
| Probation | points < 0  | `AlertTriangle` (lucide) | `bg-red-100 text-red-800`       |
