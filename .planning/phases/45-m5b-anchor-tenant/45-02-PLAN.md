**Step C — Create merits services (src/entities/merit/services/index.ts):**

getEffectivePoints(userId, tenantId, tx?): Promise<{ recognition: number; disciplinary: number; overall: number }>

- Query behaviorRecords: SUM(recognitionPoints) WHERE MERIT + ACTIVE/UPHELD + not expired, SUM(disciplinaryPoints) WHERE WARNING/INFRACTION + ACTIVE/UPHELD + not expired
- overall = recognition - disciplinary (disciplinary is stored as positive int, meaning "penalty points")
- Use notDeleted() + status IN ('ACTIVE', 'UPHELD') + (expiresAt IS NULL OR expiresAt > now())
- OVERTURNED records contribute 0 to standing
- DISPUTED records: recognitionPoints count (innocent until proven), disciplinaryPoints DON'T count (disputed penalty)

getStandingTier(overall: number, thresholds?: Partial<typeof DEFAULT_TIER_THRESHOLDS>): StandingTier

- Pull thresholds from tenant settings if available (check TenantSettings or config), fallback to DEFAULT_TIER_THRESHOLDS
- overall >= GOLD → 'GOLD', >= SILVER → 'SILVER', >= BRONZE → 'BRONZE', > PROBATION && < BRONZE → 'WATCHLIST', <= PROBATION → 'PROBATION'

checkAndEscalateStanding(userId, tenantId, tx?): Promise<{ escalated: boolean; type?: 'REVIEW_FLAG' | 'SUSPENSION_RECOMMENDATION' }>

- Count ACTIVE + UPHELD infractions for the user in this tenant (count WHERE behaviorType = 'INFRACTION' AND status IN ('ACTIVE', 'UPHELD') AND not deleted AND not expired)
- If count >= ESCALATION_THRESHOLDS.SUSPENSION_RECOMMENDATION → writeAuditLog SUSPENSION_RECOMMENDATION + create Notification for admin users with type `SUSPENSION_RECOMMENDATION`
- Else if count >= ESCALATION_THRESHOLDS.REVIEW_FLAG → writeAuditLog REVIEW_FLAG + create Notification for admin users with type `REVIEW_FLAG`
- Else: no-op
- This replaces the old "score < 0 → flag" logic

getStandingTierConfig(tier: StandingTier): { label: string; publicLabel: string; icon: string; colorClasses: string }

- Public labels per Concern 5: Gold/Silver/Community Member (for Bronze), Watchlist/Probation hidden from public
