**Pattern for each file (repeat for all 5 files):**

1. Find the import line:

   ```
   import { useTranslation } from 'react-i18next';
   ```

   Replace with:

   ```
   import { useSafeTranslation } from '@shared/lib';
   ```

2. Find the hook call:

   ```
   const { t } = useTranslation('common');
   // or
   const { t } = useTranslation();
   ```

   Replace with:

   ```
   const { tx } = useSafeTranslation('common');
   // or
   const { tx } = useSafeTranslation();
   ```

   Keep the namespace parameter if present.

3. For every `t('key')` call, replace with `tx('key', 'English Fallback')`. The fallback string must be the current English text that renders for that key. To determine the fallback:
   - For `t('spaces.home')` → `tx('spaces.home', 'Home')`
   - For `t('spaces.services')` → `tx('spaces.services', 'Services')`
   - For `t('spaces.messages')` → `tx('spaces.messages', 'Messages')`
   - For `t('spaces.community')` → `tx('spaces.community', 'Community')`
   - For `t('spaces.admin')` → `tx('spaces.admin', 'Admin')`
   - For `t('nav.home')` → `tx('nav.home', 'Home')`
   - For `t('nav.settings')` → `tx('nav.settings', 'Settings')`
   - For any `t()` call referencing a key whose fallback is unclear from context, use the key itself after the last dot, title-cased (e.g., `t('admin.users')` → `tx('admin.users', 'Users')`)

4. Handle variadic arguments. If the existing code is `t('key', { count: 5 })`, convert to `tx('key', 'fallback', { count: 5 })`.

5. Do NOT remove any existing `t` usage from useSafeTranslation if the component uses it for non-rendered purposes (e.g., console.log). But if the component only uses `tx`, destructure only `tx`.

| ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| SSR→Client | Translation strings rendered server-side must match first client render — useSafeTranslation ensures English fallback in both |

## Assets

| Asset                    | Sensitivity                   | Location                 |
| ------------------------ | ----------------------------- | ------------------------ |
| Translation keys         | Low (non-sensitive UI labels) | i18n JSON locale files   |
| English fallback strings | Low (public-facing UI text)   | Inline in component code |

## STRIDE Threat Register

| Threat ID | Category               | Component                  | Disposition | Mitigation Plan                                                                                   |
| --------- | ---------------------- | -------------------------- | ----------- | ------------------------------------------------------------------------------------------------- |
| T-45-19   | Tampering              | tx() fallbacks             | accept      | Fallback strings are hardcoded English — no attacker can modify them without a code change        |
| T-45-20   | Information Disclosure | i18n keys in client bundle | accept      | Translation keys are public metadata, not secrets — they map to visible UI labels                 |
| T-45-21   | Denial of Service      | i18n namespace loading     | accept      | All 16 namespaces already exist and are small (~KB each) — migration doesn't change load behavior |
