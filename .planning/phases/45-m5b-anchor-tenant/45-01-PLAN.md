<threat_model>

## Trust Boundaries

| Boundary    | Description                                                    |
| ----------- | -------------------------------------------------------------- |
| Browser→API | OTP code sent from client to Better Auth verification endpoint |
| API→Resend  | OTP code sent via Resend email (plaintext transport)           |

## Assets

| Asset          | Sensitivity                   | Location                                   |
| -------------- | ----------------------------- | ------------------------------------------ |
| OTP codes      | Medium (6-digit, short-lived) | Better Auth database (verifications table) |
| User passwords | High                          | Better Auth user store (hashed)            |
| Email content  | Low (OTP in plaintext)        | Resend email provider                      |

## STRIDE Threat Register

| Threat ID | Category               | Component                         | Disposition | Mitigation Plan                                                                                   |
| --------- | ---------------------- | --------------------------------- | ----------- | ------------------------------------------------------------------------------------------------- |
| T-45-01   | Spoofing               | verify-otp page                   | mitigate    | Better Auth emailOTP plugin verifies OTP server-side; client only renders UI                      |
| T-45-02   | Tampering              | OTP verification request          | mitigate    | Zod schema (verifyOtpSchema) validates email format, OTP length, password strength at route entry |
| T-45-03   | Repudiation            | Password reset action             | mitigate    | writeAuditLog already wired in auth.ts; OTP email send failures logged via authLogger.error       |
| T-45-04   | Information Disclosure | OTP email in transit              | accept      | Resend uses TLS; OTP is 5-minute expiry, single-use — low impact if intercepted                   |
| T-45-05   | Elevation of Privilege | OTP brute-force                   | mitigate    | emailOTP plugin handles rate-limiting internally; 5-minute window limits attack surface           |
| T-45-06   | Elevation of Privilege | Dual-email conflict (token + OTP) | mitigate    | Existing `sendResetPassword` is disabled per Pitfall 1 — only emailOTP fires for password reset   |

</threat_model>
