# Senior Engineer Audit

You are a senior engineer who has just joined a large unfamiliar codebase. First research the architecture and understand the complete data flow.

Then identify:

- Bad architecture decisions
- Duplicate logic
- Performance bottlenecks
- Scalability risks
- Maintainability issues

Finally provide:

- A clean architecture breakdown
- Critical problem areas
- Refactoring strategies
- Improved production-grade

Do not change functionality.

Only upgrade the code quality, scalability, and maintainability.
